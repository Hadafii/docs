---
title: "Cara Pindah/Migrasi Server"
---

<Info>
  Pastikan server sudah support SFTP atau FTP
</Info>

<Steps>
  <Step title="Buka Server Sebelumnya">
    Lihat SFTP detail di server yang ingin dipindahkan. 

    <Frame>
      ![Image](/images/migrasi/sftp-detail.png)
    </Frame>

    1. Kalau di RaeHost, SFTP details berada di tab `Settings` 
    2. Pilih menu `SFTP Access`
    3. Terdapat server address untuk SFTP dari server yang ingin dipindahkan
    4. Terdapat juga username
  </Step>
  <Step title="Masuk ke Server Tujuan Pindah">
    <Frame>
      ![Image](/images/migrasi/isi-data.png)
    </Frame>

    
    1. Masuk ke tab `Server Importer`
    2. Pilih protocol yang sudah didapat dari SFTP server sebelumnya
    3. Isi port dari SFTP server yang sudah di dapat sebelumnya
    4. Masukkan host server **(Tanpa sftp:// dan port)**
    5. Masukkan username dari akun SFTP kamu yang sudah di dapat pada server sebelumnya
    6. Masukkan password panel kamu
    7. Tombol `Connect & Browse` untuk menghubungkan server yang ingin dipindahkan ke server tujuan.
  </Step>
  <Step title="Isi Informasi File">
    <Frame>
      <img
        src="/images/migrasi/delete-file.png"
        alt="Image"
        title="Image"
        className="mx-auto"
        style={{ width:"75%" }}
      />
    </Frame>

    1. Pastikan sudah connect 
    2. Nomor 2 berisi pilihan untuk memilih mau file apa aja yang dipindahkan (Jika ingin semua, centang untuk semua file)
    3. Nomor 3 berisi apakah mau menghapus semua file pada server tujuan (Better aktifkan ini)
    4. Nomor 4 berisi tombol agar kegiatan import dilakukan.
  </Step>
  <Step title="Konfirmasi Hapus Isi Server">
    Akan muncul konfirmasi, tulis `WIPE` dan klik tombol `Wipe & Import`.

    <Frame>
      ![Image](/images/migrasi/wipe.png)
    </Frame>
  </Step>
  <Step title="Tunggu Hingga Files Selesai di Transfer">
    Pada tab `Console`, tunggu hingga semua file berpindah.

    <Frame>
      ![Image](/images/migrasi/complete.png)
    </Frame>
  </Step>
</Steps>
