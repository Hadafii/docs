<Card title="Catatan Renewal" type="note">
  - Masa aktif dihitung dari tanggal expired sebelumnya, bukan dari tanggal pembayaran _renewal_
  - _Renewal_ dapat dilakukan kapan saja sebelum server _expired_
  - RaeHost memberikan toleransi hingga H\+3 setelah masa aktif habis
  - Jika server tidak diperpanjang melewati H\+3, server akan dihapus otomatis oleh sistem
</Card>

<Tip>
  Disarankan melakukan _renewal_ sebelum masa aktif habis untuk menghindari downtime atau penghapusan data server.
</Tip>
