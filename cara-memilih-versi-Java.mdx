- [Forge](#forge)
- [NeoForge](#neoforge)
- [Fabric](#fabric)

## Forge

<Steps>
  <Step title="Pergi ke Startup">
    Di sidebar Panel, klik menu **Startup**.

    <Frame>
      ![Image](/images/image-108.png)
    </Frame>
  </Step>
  <Step title="Ubah Minecraft Version">
    Di bagian **Variables**, isi field **Minecraft Version** dengan versi Minecraft yang ingin digunakan. Contoh: `1.20.1`
  </Step>
  <Step title="Ubah Forge Version">
    Isi field **Forge Version** dengan versi Forge yang ingin digunakan, menggunakan format:

    ```text
    (Versi Minecraft)-(Build Forge)
    ```

    Contoh: `1.20.1-47.4.20`

    <Note>
      Cek daftar versi Forge yang tersedia di [files.minecraftforge.net](https://files.minecraftforge.net/net/minecraftforge/forge/). Pastikan versi yang dimasukkan valid — jika salah, proses install akan gagal.
    </Note>
  </Step>
  <Step title="Ubah Build Type">
    Di field **Build Type**, pilih tipe build yang ingin digunakan:

    | Nilai | Keterangan |
    | --- | --- |
    | `recommended` | Versi stabil yang direkomendasikan |
    | `latest` | Versi terbaru (bisa belum stabil) |
  </Step>
  <Step title="Pilih Versi Java">
    Di bagian **Docker Image**, pilih versi Java yang sesuai dengan versi Minecraft. Lihat tabel di bawah untuk referensi.
  </Step>
  <Step title="Restart Server">
    Setelah semua diisi, **restart server** agar perubahan berlaku.
  </Step>
</Steps>

## Fabric

<Steps>
  <Step title="Pergi ke Startup">
    Di sidebar Panel, klik menu **Startup**.

    <Frame>
      ![Preview (1)](/images/preview-\(1\).webp)
    </Frame>
  </Step>
  <Step title="Ubah Minecraft Version">
    Di bagian **Variables**, isi field **Minecraft Version** dengan versi Minecraft yang ingin digunakan. Contoh: `1.20.1`

    <Note>
      Gunakan `latest` untuk install versi terbaru secara otomatis, atau `snapshot` untuk versi snapshot terbaru.
    </Note>
  </Step>
  <Step title="Ubah Fabric Version">
    Isi field **Fabric Version** dengan versi Fabric yang ingin digunakan. Isi dengan `latest` untuk menggunakan versi terbaru.
  </Step>
  <Step title="Ubah Fabric Loader Version">
    Isi field **Fabric Loader Version** dengan versi Fabric Loader yang ingin digunakan. Isi dengan `latest` untuk menggunakan versi terbaru.
  </Step>
  <Step title="Pilih Versi Java">
    Di bagian **Docker Image**, pilih versi Java yang sesuai dengan versi Minecraft. Lihat tabel di bawah untuk referensi.
  </Step>
  <Step title="Restart Server">
    Setelah semua diisi, **restart server** agar perubahan berlaku.
  </Step>
</Steps>

## Tabel Versi Minecraft & Java

| Versi Minecraft | Java yang Dibutuhkan |
| --- | --- |
| 1.8 – 1.16.5 | Java 8 |
| 1.17 | Java 16 |
| 1.17.1 – 1.20.4 | Java 17 |
| 1.20.5 – 1.21.x | Java 21 |
| 1.21.11 – 1.26\+ | Java 25 |

<Warning>
  Pastikan versi Java sudah sesuai dengan versi Minecraft yang digunakan. Java yang salah akan menyebabkan server gagal start.
</Warning>
