title: "Cara Pasang Mod di Server"
---

## Manual

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Kemudian stop server dengan menekan tombol `Stop` seperti yang ditunjukkan oleh nomor 2. Pastikan servermu offline seperti yang ditunjukkan oleh nomor 1.

    <Frame>
      ![Server Offline](/images/server-offline.png)
    </Frame>
  </Step>
  <Step title="Download Mod">
    <Steps>
      <Step title="Masuk ke Web Curseforge">
        <Info>
          [https://www.curseforge.com/](https://www.curseforge.com/)
        </Info>

        Setelah masuk ke web nya, cari Hytale

        <Frame>
          ![Curse Forgde Hytale](/images/curse-forgde-hytale.png)
        </Frame>
      </Step>
      <Step title="Pilih Kategori">
        Pilih `Mod` pada kategori

        <Frame>
          ![Categories Mod](/images/categories-mod.png)
        </Frame>
      </Step>
      <Step title="Cari Mod">
        Cari Mod yang kamu inginkan

        <Frame>
          ![Find Mod](/images/find-mod.png)
        </Frame>
      </Step>
      <Step title="Download File">
        <Frame>
          ![Download Mod](/images/download-mod.png)
        </Frame>

        1. Klik Mod yang kamu ingin seperti berikut
        2. Plih tab `Files`
        3. Klik icon detail
        4. Klik menu `Download File`. Tunggu hingga file terdownload sempurna.
      </Step>
    </Steps>
  </Step>
  <Step title="Upload File">
    Kembali ke [https://panel.raehost.com/](https://panel.raehost.com/) dan masuk ke tab `Files`. Kemudian klik folder `mods` seperti berikut:

    <Frame>
      <img
        src="/images/file-mod.png"
        alt="File Mod"
        className="mx-auto"
        style={{ width:"76%" }}
      />
    </Frame>

    Upload fils yang sudah di download dengan cara di drag and drop atau klik tombol `Upload` seperti yang ditunjuk oleh nomor 1. Setelahnya file akan tersimpan di `File Manager` seperti nomor 2.

    <Frame>
      ![File In](/images/file-in.png)
    </Frame>
  </Step>
  <Step title="Start Server">
    Klik tombol `Start` pada tab `Console`

    <Frame>
      ![Start Hytale](/images/start-hytale.png)
    </Frame>
  </Step>
  <Step title="Autentikasi Akun Melalui Hytale">
    <Frame>
      ![Server Mark Uhuy](/images/server-mark-uhuy.png)
    </Frame>

    Akan muncul `Server mark as running` tulis pada command console seperti berikut:

    ```text
    auth login device
    ```

    Akan muncul link verifikasi seperti gambar berikut.

    <Frame>
      ![Link Verify](/images/link-verify.png)
    </Frame>

    Klik tombol `Approve` seperti dibawah ini.

    <Frame>
      <img
        src="/images/approve-autentikasi.png"
        alt="Approve Autentikasi"
        title="Approve Autentikasi"
        className="mx-auto"
        style={{ width:"85%" }}
      />
    </Frame>

    Kemudian klik Login menggunakan Google

    <Frame>
      <img
        src="/images/login-hytale.png"
        alt="Login Hytale"
        title="Login Hytale"
        className="mx-auto"
        style={{ width:"77%" }}
      />
    </Frame>

    Akun akan terverifikasi, seperti berikut

    <Frame>
      <img
        src="/images/authorize.png"
        alt="Authorize"
        title="Authorize"
        className="mx-auto"
        style={{ width:"90%" }}
      />
    </Frame>
  </Step>
</Steps>
