Untuk masuk ke server Palworld, kamu perlu mengetahui **IP** dan **Port** server terlebih dahulu. Berikut cara mendapatkan dan menggunakannya.

---

## Langkah 1: Cek IP & Port Server

<Steps>
  <Step title="Buka Panel RaeHost">
    Login dan buka Panel server Palworld kamu di RaeHost.
  </Step>
  <Step title="Lihat IP & Port">
    <Frame>
      ![Palworld Ip](/images/palworld-ip.png)
    </Frame>

    Di halaman utama Panel, kamu bisa melihat **IP Address** dan **Port** server di bagian atas halaman.

    <Note>
      Catat IP dan Port ini — kamu akan membutuhkannya saat join di dalam game.
    </Note>
  </Step>
</Steps>

---

## Langkah 2: Join Server di Palworld

<Steps>
  <Step title="Buka Palworld">
    Jalankan game Palworld di PC kamu.
  </Step>
  <Step title="Pilih Join Multiplayer Game">
    Di menu utama, klik **Join Multiplayer Game**.
  </Step>
  <Step title="Masukkan IP & Port">
    <Frame>
      ![Palworld Join](/images/palworld-join.png)
    </Frame>

    Di bagian bawah layar, masukkan IP dan Port server dengan format:

    ```text
    (IP Address):(Port)
    ```

    Contoh:

    ```text
    123.456.789.0:8211
    ```
  </Step>
  <Step title="Masukkan Password (Jika Ada)">
    <Frame>
      ![Palworld Password](/images/palworld-password.png)
    </Frame>

    Jika server menggunakan password, kamu akan diminta memasukkan password sebelum bisa masuk.

    <Note>
      Jika kamu adalah admin server dan ingin mengatur password, bisa diubah  melalui **Panel → Startup**.
    </Note>
  </Step>
  <Step title="Klik Connect">
    Klik tombol **OK **dan tunggu hingga berhasil masuk ke server.
  </Step>
</Steps>

---

## Troubleshooting

### Tidak Bisa Connect / Connection Failed

- Pastikan server dalam kondisi **Running** di Panel.
- Pastikan IP dan Port yang dimasukkan sudah benar.
- Pastikan tidak ada spasi di antara IP dan Port.
- Coba restart server dari Panel lalu coba join kembali.

### Password Salah

- Pastikan password yang dimasukkan sudah benar (perhatikan huruf besar/kecil).
- [Hubungi admin](https://clients.raehost.com/tickets) server jika tidak tahu passwordnya.

### Stuck di Loading Screen

- Coba restart game Palworld.
- Periksa koneksi internet kamu.
- Pastikan versi game kamu sama dengan versi server.

---

<Note>
  Pastikan versi Palworld di client kamu sama dengan versi server. Perbedaan versi dapat menyebabkan gagal connect.
</Note>
