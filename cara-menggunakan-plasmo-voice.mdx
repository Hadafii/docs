---
title: "Cara Menggunakan Plasmo Voice"
---

Plasmo Voice adalah plugin voice chat untuk Minecraft yang memungkinkan pemain berkomunikasi secara langsung di dalam game. Plugin ini mendukung fitur **proximity voice chat**, sehingga suara pemain akan terdengar berdasarkan jarak antar pemain di dalam dunia Minecraft. Dengan Plasmo Voice, pemain tidak perlu menggunakan aplikasi pihak ketiga seperti Discord untuk berkomunikasi saat bermain. 

<Note>
  Fitur ini hanya berjalan di Minecraft Java Edition. Gunakan `mods` jika kamu menggunakan **Forge**, **NeoForge**, dan **Fabric**. Gunakan `plugin` jika kamu menggunakan **Bukkit**, **Spigot**, **Paper**, dan **Purpur**.  Jika folder `plugins` belum ada, pastikan server sudah pernah di-start minimal sekali dengan software yang mendukung plugin (Paper, Spigot, dll).
</Note>

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/). Pastikan server kamu offline.

    <Frame>
      <img
        src="/images/plugin/stop-server.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Install Plugin/Mods">
    <Frame>
      <img
        src="/images/plasmo/install.png"
        alt="Install Plugin Plasmo"
        title="Install Plugin Plasmo"
        className="mx-auto"
      />
    </Frame>

    1. Klik tab `Plugins` atau `Mods`
    2. Cari plugin/mod `Plasmo Voice` dengan menggunakan fitur pencarian
    3. Klik tombol `Install`
  </Step>
  <Step title="Pilih Sesuai Versi Server Kamu">
    <Frame>
      ![Image](/images/plasmo/version.png)
    </Frame>
  </Step>
  <Step title="Start Server Kembali">
    <Frame>
      ![Image](/images/plasmo/installed.png)
    </Frame>
  </Step>
  <Step title="Stop Server">
    Jika server sudah berstatus `running`, stop kembali server nya.

    <Frame>
      ![Image](/images/plugin/stop-server.png)
    </Frame>
  </Step>
  <Step title="Cari Port Voice">
    Masuk ke tab `Network`. Pastikan kamu memiliki 2 port. Copy port yang kedua (ditandai dengan tulisan `Make Primary`).

    <Frame>
      ![Image](/images/simple/network.png)
    </Frame>

    <Note>
      Jika kamu hanya memiliki 1 port pada tab `Network` silahkan buat tiket untuk meminta port tambahan. 
    </Note>
  </Step>
  <Step title="Masuk ke file Plasmo Voice">
    Masuk ke tab `Files` , lalu buka file

    

    <Frame>
      ![Config](/images/plasmo/config.png)
    </Frame>

    <Frame>
      ![Edit Config](/images/plasmo/config-2.png)
    </Frame>

    Ikuti steps berikut ini:
    1. Masuk ke tab `Files`
    2. Buka file ini `/home/container/plugins/PlasmoVoice/config.toml`
    3 **Masukkan port kedua server kamu.** 
    4. **Sesuaikan pengaturan** `voice.proximity `**sesuai kebutuhan.** Pada bagian `distances`, kamu dapat menambahkan daftar jarak yang tersedia untuk pemain. Sedangkan `default_distance` digunakan untuk menentukan jarak voice chat default yang akan digunakan.
    5. Klik `Save` untuk menyimpan perubahan.

    contoh:

    ```text
    distances = [4, 8, 16, 32]
    default_distance = 8
    ```
  </Step>
  <Step title="Start Kembali Server">
    Plasmo Voice sudah dapat digunakan.

    <Frame>
      ![Start Plasmo](/images/plasmo/works.png)
    </Frame>

    <Info>
      Pastikan Minecraft kamu sudah terpasang mod **Plasmo Voice**. Jika mod tersebut tidak terinstal di sisi client, fitur voice chat tidak akan berfungsi meskipun plugin Plasmo Voice sudah terpasang dan dikonfigurasi dengan benar di server.
    </Info>
  </Step>
</Steps>
