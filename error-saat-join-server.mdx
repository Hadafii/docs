```text
java.net.ConnectException: Connection refused
```

**Penyebab:** Server sedang tidak berjalan atau port salah.

**Solusi:**

- Tutup Minecraft lalu buka kembali.
- Pastikan server dalam kondisi **Running** di Panel.
- Pastikan IP dan port yang digunakan sudah benar.
- Coba restart server dari Panel.

### Connection Timed Out

<Frame>
  ![Image](/images/image-106.png)
</Frame>

```text
java.net.ConnectException: Connection timed out
```

**Penyebab:** Client tidak bisa menjangkau server dalam waktu yang ditentukan.

**Solusi:**

- Tutup Minecraft lalu buka kembali.
- Pastikan server sedang **Running** di Panel dan pastikan ping server terdeteksi.
- Periksa koneksi internet kamu.
- Pastikan IP server yang digunakan sudah benar.
- Coba beberapa saat lagi, mungkin server sedang dalam proses start.

### You Are Banned

  ![Ban Unban Thumbnail](/images/ban-unban-thumbnail.png)
</Frame>

```text
You are banned from this server.

```

**Penyebab:** Akun atau IP kamu di-ban oleh admin server.

**Solusi (untuk Admin):**

- Unban pemain via Console:
  ```text

  ```
- Unban IP via Console:
  ```text

  ```

**Solusi (untuk Pemain):**

- Hubungi admin server untuk meminta unban.

### Flying is Not Enabled

<Frame>
  ![Having Trouble With The Jump Spell Via Ars Nouveau Mod In A V0 Z5c2wwmpybza1](/images/having-trouble-with-the-jump-spell-via-ars-nouveau-mod-in-a-v0-z5c2wwmpybza1.webp)
</Frame>

```text
Flying is not enabled on this server
```

**Penyebab:** Pemain terdeteksi terbang, tapi `allow-flight` dinonaktifkan di server.

**Solusi (untuk Admin):**

- Set `allow-flight=true` di `server.properties` lalu restart server.
- Atau install plugin anti-cheat yang lebih akurat untuk mengurangi false positive.

### Internal Exception

<Frame>
  ![122244361 379531530085319 1659862123042933208 N](/images/122244361_379531530085319_1659862123042933208_n.png)
</Frame>

```text
Internal Exception: io.netty.handler.codec.DecoderException
```

**Penyebab:** Terjadi error komunikasi antara client dan server, biasanya karena plugin yang tidak kompatibel atau versi yang tidak cocok.

**Solusi:**

- Pastikan versi client dan server cocok.
- Coba disable plugin satu per satu untuk mencari plugin yang bermasalah.
- Restart server dari Panel.

---

### Incomplete Set of Tags from Server

```text
Incomplete set of tags received from server
```

**Penyebab:** Mod yang ada di client tidak cocok atau tidak sinkron dengan mod yang terpasang di server. Biasanya terjadi setelah ada mod yang ditambahkan, dihapus, atau diupdate di salah satu sisi saja.

**Solusi:**

- **Samakan mod client dengan server** — Buka **Panel → Files → mods**, download semua mod dari server, lalu ganti seluruh isi folder `.minecraft/mods` di komputer kamu dengan mod tersebut.
- **Reinstall modpack** — Jika menggunakan modpack, pastikan versi modpack di client dan server sama persis. Lihat panduan [Cara Install Modpack](/cara-install-modpack).
- **Hapus mod yang baru ditambahkan** — Jika error muncul setelah menambahkan mod baru, hapus mod tersebut dari **Panel → Files → mods** lalu restart server.

<Note>
  Selalu informasikan perubahan mod ke semua pemain sebelum diterapkan di server agar client dan server tetap sinkron.
</Note>

## Minecraft Bedrock Edition

Minecraft Bedrock Edition menggunakan nama-nama unik (diambil dari nama item/mob Minecraft) sebagai kode error. Berikut daftar error yang paling sering ditemui.

### Solusi Umum (Coba Ini Dulu)

Sebelum melihat error spesifik, coba langkah-langkah berikut yang sering menyelesaikan banyak masalah:

- Tutup Minecraft sepenuhnya lalu buka kembali
- Restart perangkat kamu
- Periksa koneksi internet
- Logout lalu login kembali ke akun Microsoft/Xbox
- Nonaktifkan VPN jika sedang aktif
- Update Minecraft ke versi terbaru
- Pastikan server sedang **Running** di Panel

### Not Allowed to Join (Allow List)

<Frame>
  ![Minecraft Bedrock Edition Allowlist Dk4bb6h6 2c EH6T](/images/minecraft-bedrock-edition-allowlist.Dk4BB6h6_2cEH6T.webp)

- Tambahkan pemain ke allow list via Console:
  ```text

  ```

- Hubungi admin server untuk meminta akses.

**Solusi (untuk Pemain):**

- Hubungi admin server untuk meminta unban.
