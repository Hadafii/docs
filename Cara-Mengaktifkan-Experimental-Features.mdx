---
title: "Cara Mengaktifkan Experimental Features (BEDROCK EDITION)"
---

Experimental Features adalah fitur-fitur yang masih dalam tahap pengembangan di Minecraft Bedrock Edition. Fitur ini berguna untuk membuat addon, script, atau mencoba konten terbaru sebelum dirilis secara resmi.

<Warning>
  Experimental Features masih dalam tahap pengembangan dan dapat menyebabkan perilaku tidak terduga atau bug pada server. Aktifkan hanya fitur yang benar-benar kamu butuhkan.
</Warning>

---

## Cara Mengaktifkan

<Steps>
  <Step title="Matikan Server">
    Pastikan server dalam kondisi **Offline** sebelum mengubah pengaturan. Klik tombol **Stop** di Panel jika server masih berjalan.
    <Frame>
      ![Image](/images/general/stop.png)
    </Frame>

    <Warning>
      Jangan mengubah pengaturan Experimental saat server sedang berjalan. Perubahan tidak akan tersimpan dengan benar dan dapat menyebabkan masalah.
    </Warning>
  </Step>
  <Step title="Buka Bedrock Config">
    <Frame>
      ![Image](/images/experimental/tutorial.png)
    </Frame>
    1. Klik tab `Bedrock Config`
    2. Klik dropdown seperti yang ditampilkan pada nomor 2
    3. Pilih `Experiments`
  </Step>
  </Step>
  <Step title="Aktifkan Fitur yang Dibutuhkan">
    <Frame>
      ![Image](/images/image-109.png "Image")
    </Frame>

    Aktifkan toggle untuk fitur Experimental yang ingin kamu gunakan. Lihat penjelasan setiap fitur di bawah.
  </Step>
  <Step title="Simpan dan Jalankan Server">
    **Start** server kembali. Fitur Experimental yang dipilih akan aktif saat server berjalan.
    <Frame>
      ![Image](/images/general/start-server.png)
    </Frame>
  </Step>
</Steps>

---

## Penjelasan Fitur Experimental

| Fitur | Fungsi | Catatan |
| --- | --- | --- |
| **Beta APIs** | Mengaktifkan akses ke Scripting API versi beta (GameTest Framework) untuk membuat addon dengan JavaScript | Wajib aktif jika addon memakai `@minecraft/server`, `@minecraft/server-ui`, atau `@minecraft/server-gametest` |
| **Custom Biomes** | Mendukung biome kustom yang didefinisikan lewat file JSON | Diperlukan jika addon menambahkan biome baru |
| **Upcoming Creator Features** | Mengaktifkan fitur creator yang sudah selesai dikembangkan tapi belum resmi dirilis | Cocok untuk mencoba fitur terbaru lebih awal |
| **Villager Trade Rebalancing** | Mengaktifkan sistem trading villager versi baru dari Mojang | Bisa mengubah harga & jenis item trading di world yang sudah ada — pertimbangkan dampaknya ke ekonomi server |
| **Experimental Creator Camera Features** | Mengaktifkan kontrol kamera eksperimental (sudut & perspektif) untuk addon/konten | — |
| **Data-Driven Jigsaw Structures** | Mengaktifkan generasi struktur jigsaw berbasis data JSON | Diperlukan untuk addon dengan struktur kustom (bangunan/dungeon prosedural) |
| **Drop 3 2025** | Mengaktifkan konten dari update Drop 3 2025 | Untuk mencoba fitur terbaru sebelum stabil |

<Note>
  Setelah mengaktifkan Experimental Features, pastikan semua pemain yang join ke server menggunakan versi Minecraft yang sama dan sudah mendukung fitur tersebut.
</Note>
