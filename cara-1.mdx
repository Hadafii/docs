---
title: "Cara Pasang Mod "
---

> Panduan ini berlaku untuk server dengan software **Forge, Fabric, atau NeoForge**.

<Steps>
  <Step title="Pastikan Server Support Mod">
    <Steps>
      <Step title="Buka panel server RaeHost kamu">
      </Step>
      <Step title="Cek bagian Egg Changer pada server">
        Pastikan server menggunakan:

        - Forge
        - Fabric
        - NeoForge

        Jika masih menggunakan Vanilla/Paper/Purpur, lakukan reinstall server lalu pilih software yang mendukung mod
      </Step>
    </Steps>
  </Step>
  <Step title="Buka Folder Mods">
    <Steps>
      <Step title="Masuk ke menu File Manager di panel">
      </Step>
      <Step title="Cari folder bernama mods">
        Folder ini biasanya otomatis tersedia jika server menggunakan Forge/Fabric/NeoForge.
      </Step>
      <Step title="Jika folder belum ada, buat folder baru dengan nama">
        `mods`
      </Step>
    </Steps>
  </Step>
  <Step title="Upload File Mod">
    <Steps>
      <Step title="Download Mod">
        > Disarankan menggunakan website yang credible ya. Jangan yang **ilegal**. Contoh web yang dapat digunakan adalah \[[https://www.curseforge.com/\](https://www.curseforge.com/)](https://www.curseforge.com/]\(https://www.curseforge.com/\))
      </Step>
      <Step title="Cek Versi">
        Pastikan versi mod sesuai dengan:

        - Versi Minecraft server
        - Versi Forge/Fabric/NeoForge yang digunakan
      </Step>
      <Step title="Upload file mod berformat .jar ke dalam folder mods">
        Kamu bisa upload dengan:

        - Drag & drop langsung ke panel
        - Menggunakan SFTP jika ukuran file besar (lebih dari 100MB)
      </Step>
    </Steps>
  </Step>
  <Step title="Restart Server">
    <Steps>
      <Step title="Setelah semua mod selesai di-upload, klik tombol Restart pada panel">
      </Step>
      <Step title="Tunggu hingga server menyala kembali">
      </Step>
      <Step title="Jika mod berhasil dimuat, daftar mod biasanya akan muncul di log console saat startup">
      </Step>
    </Steps>
  </Step>
</Steps>

<Info>
  ## Tips Penting

  - Gunakan mod dengan versi yang sesuai dengan server.
  - Jangan mencampur mod dengan loader berbeda:
    - Forge ≠ Fabric
    - Fabric ≠ NeoForge
  - Jika server crash setelah memasang mod:
    1. Buka menu **Console**
    2. Cek error log
    3. Biasanya terdapat mod yang konflik atau tidak kompatibel
</Info>
