## Troubleshooting

<AccordionGroup>
  <Accordion title="Server Crash Setelah Install Mod">
    ### Penyebab

    - Mod tidak kompatibel.
    - Konflik antar mod.
    - Dependency belum terpasang.

    ### Solusi

    - Hapus mod terakhir.
    - Install mod satu per satu.
    - Gunakan versi mod yang sesuai.
  </Accordion>

  <Accordion title="Server Stuck Starting">
    ### Penyebab

    - Mod rusak.
    - Mod tidak mendukung versi Palworld terbaru.

    ### Solusi

    - Hapus mod yang baru diinstall.
    - Restart server.
    - Periksa Console untuk mengetahui mod yang menyebabkan error.
  </Accordion>

  <Accordion title="Player Tidak Bisa Join">
    ### Penyebab

    - Client belum menginstall mod yang diperlukan.
    - Versi mod berbeda.
    - Mod server tidak kompatibel.

    ### Solusi

    - Samakan versi mod.
    - Install dependency yang diperlukan.
    - Restart server.
  </Accordion>

  <Accordion title="Mod Tidak Berfungsi">
    ### Penyebab

    - File berada di folder yang salah.
    - Mod hanya mendukung Client.
    - Server belum direstart.

    ### Solusi

    - Pastikan lokasi file benar.
    - Pastikan mod mendukung Dedicated Server.
    - Restart server.
  </Accordion>
</AccordionGroup>

## Tips

<Tip>
  Install **satu mod terlebih dahulu**, kemudian lakukan pengujian sebelum memasang mod berikutnya. Cara ini memudahkan menemukan mod yang menyebabkan masalah.
</Tip>

<Tip>
  Simpan salinan file mod asli agar lebih mudah melakukan rollback jika terjadi crash setelah update.
</Tip>

## Hal yang Perlu Diperhatikan

<Warning>
  - Jangan menginstall mod yang dibuat untuk versi Palworld yang berbeda.
  - Jangan menghapus dependency yang dibutuhkan mod lain.
  - Selalu restart server setelah menambah atau menghapus mod.
  - Jika server crash setelah install mod, hapus mod terakhir yang dipasang terlebih dahulu.
</Warning>

---

## Butuh Bantuan?

Jika server masih gagal berjalan setelah menghapus mod, silakan hubungi tim support dengan menyertakan:

- Screenshot error.
- Log server.
- Daftar mod yang digunakan.
- Versi Palworld.
- Nama mod yang terakhir diinstall.
