## Bedrock Edition

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Kemudian stop server dengan menekan tombol `Stop` seperti yang ditunjukkan oleh nomor 1.

    <Frame>
      ![Image](/images/image-64.png)
    </Frame>
  </Step>
  <Step title="Hapus World Lama">
    Ikuti tata cara berikut:

    <Frame>
      ![Image](/images/image-65.png)
    </Frame>

    1. Klik tab `Files` seperti yang ditunjukkan pada nomor 1
    2. Cari file `worlds` seperti yang ditunjukkan pada nomor 2
    3. Klik icon detail pada file `worlds` 
    4. Pilih menu `Delete` 
    5. Klik tombol `Delete` seperti gambar berikut

    <Frame>
      <img
        src="/images/image-66.png"
        alt="Image"
        title="Image"
        className="mx-auto"
        style={{ width:"74%" }}
      />
    </Frame>
  </Step>
  <Step title="Start Server">
    Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

    <Frame>
      ![Image](/images/image-67.png)
    </Frame>
  </Step>
</Steps>
