---
title: "Cara Reset Dunia"
---

<Warning>
  Fitur ini hanya digunakan jika benar-benar ingin memulai dunia baru! Semua progress lama akan hilang!
</Warning>

Lihat tutorial reset untuk tipe minecraft yang kamu inginkan:
- [Java Edition](#java-edition)
- [Bedrock Edition](#bedrock-edition)
- [Ambil Data di Trash](#restore-trash)

## Java Edition

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Kemudian stop server dengan menekan tombol `Stop` seperti yang ditunjukkan oleh nomor 1.

    <Frame>
      ![Image](/images/general/login-panel.png)
    </Frame>
  </Step>
  <Step title="Hapus World Lama">
    Masuk ke tab `Files` kemudian hapus file berikut

    <Frame>
      ![Hapus World Java](/images/reset/delete-world-java.png)
    </Frame>

    1. Hapus file `world`, `world_nether`, dan `world_the_end` seperti yang ditunjukkan oleh nomor 2 dari gambar diatas.
    2. Klik tombol `Delete` seperti yang ditunjukkan oleh nomor 3 dari gambar diatas.
  </Step>
  <Step title="Start Server">
    Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

    <Frame>
      ![Image](/images/image-67.png)
    </Frame>
  </Step>
  <Step title="Pilih Metode Delete">
    Ikuti tata cara berikut:

    <Frame>
      ![Image](/images/reset/modal-java.png)
    </Frame>

    Saat menghapus file, terdapat dua pilihan:
    1. **Trash**. File akan dipindahkan ke Trash dan masih dapat dipulihkan kembali jika diperlukan (maximal 7 hari).
    2. **Delete Permanently**. File akan dihapus secara permanen dan tidak dapat dikembalikan.
    > ⚠️ Pastikan memilih opsi yang sesuai karena **Delete Permanently** akan menghapus data secara permanen. 
  </Step>
  <Step title="Start Server">
    Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

    <Frame>
      ![Image](/images/general/start-server.png)
    </Frame>
  </Step>
</Steps>

## Restore Trash
<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Kemudian stop server dengan menekan tombol `Stop` seperti yang ditunjukkan oleh nomor 1.

    <Frame>
      ![Image](/images/general/stop-server.png)
    </Frame>
  </Step>
  <Step title="Hapus World Saat Ini">
    Ikuti tata cara berikut:

    <Frame>
      ![Image](/images/reset/delete-world.png)
    </Frame>

    1. Klik tab `Files` seperti yang ditunjukkan pada nomor 1
    2. Cari file `worlds` seperti yang ditunjukkan pada nomor 2
    3. Pilih tombol `Delete` 
  </Step>
  <Step title="Klik Tombol Trash">
    Ikuti tata cara berikut:

    <Frame>
      ![Image](/images/reset/trash-bedrock.png)
    </Frame>
    Data world lama masih ada, maximal data masih tersimpan di trash selama 7 hari. Setelah 7 hari, data akan terhapus otomatis oleh sistem.
  </Step>
  <Step title="Klik Restore">
    Ikuti tata cara berikut:

    <Frame>
      ![Image](/images/reset/isi-trash-bedrock.png)
    </Frame>
  </Step>
  <Step title="Start Server">
    Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

    <Frame>
      ![Image](/images/general/start-server.png)
    </Frame>
  </Step>
</Steps>
