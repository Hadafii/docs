---
title: "Website RaeHost"
---

Pada website utama RaeHost, kamu dapat melakukan seluruh pengelolaan layanan dan akun. Disini kamu bisa:

- Membeli server Minecraft dan layanan lainnya
- Melakukan pembayaran melalui QRIS dan e-Wallet
- Melihat status pesanan dan invoice
- Memantau masa aktif server
- Membuka ticket bantuan ke tim support
- Melihat promo dan pengumuman resmi
- Mengelola akun dan informasi billing

Website utama digunakan untuk pengelolaan layanan dan transaksi.
