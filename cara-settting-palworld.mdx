---
title: "Cara Setting PalWorldSettings.ini"
description: "Panduan lengkap mengatur file konfigurasi PalWorldSettings.ini untuk server Palworld di RaeHost."
---

`PalWorldSettings.ini` adalah file konfigurasi utama server **Palworld** yang digunakan untuk mengatur gameplay, multiplayer, PvP, guild, hingga berbagai fitur server.

## Lokasi File

```text
/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini
```

Buka melalui **Panel → Files** lalu navigasi ke folder tersebut.

<Note>
  Setelah mengubah `PalWorldSettings.ini`, lakukan **Restart Server** agar perubahan diterapkan.
</Note>

---

# Pengaturan Umum

| Setting | Default | Deskripsi |
| --- | --- | --- |
| `Difficulty` | `None` | Tingkat kesulitan server. |
| `ServerName` | `"Raehost Palworld Server"` | Nama server. |
| `ServerDescription` | `"Raehost Palworld Server"` | Deskripsi server. |
| `ServerPlayerMaxNum` | `32` | Maksimal pemain. |
| `CoopPlayerMaxNum` | `4` | Maksimal pemain co-op. |
| `AdminPassword` | `""` | Password admin. |
| `ServerPassword` | `""` | Password untuk join server. |
| `PublicPort` | `25600` | Port publik server. |
| `Region` | `""` | Region server. |

### Difficulty

| Nilai | Keterangan |
| --- | --- |
| `None` | Custom |
| `Casual` | Easy |
| `Normal` | Normal |
| `Hard` | Hard |

<Warning>
  Jangan bagikan `AdminPassword` kepada pemain lain.
</Warning>

# PvP & Multiplayer

| Setting | Default | Deskripsi |
| --- | --- | --- |
| `bIsPvP` | `False` | Mengaktifkan PvP. |
| `bEnablePlayerToPlayerDamage` | `False` | Pemain dapat saling menyerang. |
| `bEnableFriendlyFire` | `False` | Friendly fire antar guild. |
| `bEnableDefenseOtherGuildPlayer` | `False` | Guild lain dapat membela diri. |
| `bHardcore` | `False` | Mode Hardcore. |
| `bPalLost` | `False` | Pal mati permanen. |

| Nilai | Efek |
| --- | --- |
| `None` | Tidak ada penalti |

| `ItemAndEquipment` | Drop item \+ equipment |
