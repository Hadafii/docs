<Steps>
  <Step title="Login ke Panel">

  <Step title="Masuk ke Tab MC Config">

    <Frame>
      ![Image](/images/image-58.png)

    Klik toggle menjadi disable agar online mode menjadi off seperti yang ditampilkan pada gambar berikut:

  </Step>

Jika setelah di restart, online mode masih off atau toggle sedang tidak works. Kamu bisa langsung hard code seperti ini:

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    Masuk ke tab `Files`seperti yang ditampilkan pada nomor 1. Kemudian cari file server.properties seperti yang ditampilkan pada nomor 2.

    Klik toggle menjadi disable agar online mode menjadi off seperti yang ditampilkan pada gambar berikut:

    <Frame>
      ![Image](/images/image-63.png)
    </Frame>
  </Step>
  <Step title="Restart Server">
    Setelahnya, pergi ke tab `Console` seperti yang ditunjukkan pada nomor 1. Kemudian klik `Restart` seperti yang ditunjukkan pada nomor 2. Online mode sudah off.

    <Frame>

    </Frame>
  </Step>

<Note>
  Perlu diketahui bahwa pada **online-mode: false**, server tidak melakukan verifikasi akun Minecraft secara resmi. Hal ini memungkinkan pihak lain untuk masuk menggunakan nama player tertentu apabila server tidak menggunakan sistem login atau pengamanan tambahan.

  Untuk itu, pemilik server **diwajibkan memperhatikan dan menerapkan langkah keamanan berikut**:

  1. Gunakan plugin/mods **login/security** agar setiap player wajib login sebelum dapat bermain.
  2. Gunakan **plugin/mods anti-cheat** untuk meminimalisir penggunaan cheat atau hack client.
  3. Jika server bersifat **private**, wajib menggunakan **whitelist** dan hanya menambahkan player yang dikenal atau dipercaya.
  4. Batasi penggunaan **operator (OP)**. Jika tidak diperlukan, disarankan untuk melakukan **deop** atau menonaktifkan akses penuh.
  5. Jangan menggunakan **plugin/mods dari sumber tidak jelas, crack, atau modifikasi tidak resmi** karena berpotensi mengandung backdoor atau celah keamanan.
  6. Lakukan **backup world secara berkala** untuk menghindari kehilangan data.
  7. Jika memungkinkan, gunakan **online-mode: true** agar server hanya menerima akun Minecraft yang valid.

  Perlu diperhatikan bahwa server dengan **online-mode: false memiliki risiko keamanan yang lebih tinggi**. Oleh karena itu, pemilik server bertanggung jawab untuk memastikan konfigurasi keamanan server telah diterapkan dengan benar untuk mencegah penyalahgunaan oleh pihak yang tidak bertanggung jawab.
</Note>
