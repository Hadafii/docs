---
title: "Cara Pasang Mod"
---

> Panduan ini berlaku untuk server dengan software **Forge, Fabric, atau NeoForge**.

<Steps>
  <Step title="Pastikan Server Mendukung Mod">
    <Steps>
      <Step title="Buka panel server RaeHost kamu">
      </Step>
      <Step title="Cek bagian Egg Changer pada server">
        Pastikan server menggunakan salah satu dari:

        - Forge
        - Fabric
        - NeoForge

        Kalau server masih memakai Vanilla, Paper, atau Purpur, ganti dulu ke software yang mendukung mod lewat `Egg Changer`.
      </Step>
    </Steps>

  </Step>
  <Step title="Buka Folder Mods">
    <Steps>
      <Step title="Masuk ke tab Files di panel">
      </Step>
      <Step title="Cari folder bernama mods">
        Folder ini biasanya otomatis tersedia kalau server memakai Forge, Fabric, atau NeoForge.
      </Step>
      <Step title="Kalau folder belum ada, buat folder baru bernama `mods`">
      </Step>
    </Steps>
  </Step>
  <Step title="Upload File Mod">
    <Steps>
      <Step title="Download mod">
        Gunakan website yang terpercaya, seperti [CurseForge](https://www.curseforge.com/) atau [Modrinth](https://modrinth.com/). Hindari mod bajakan atau dari sumber yang tidak jelas.
      </Step>
      <Step title="Cek versi">
        Pastikan versi mod sesuai dengan:

        - Versi Minecraft server
        - Versi Forge/Fabric/NeoForge yang digunakan
      </Step>
      <Step title="Upload file mod berformat .jar ke folder mods">
        Kamu bisa upload dengan cara:

        - Drag & drop langsung ke panel
        - Menggunakan SFTP kalau ukuran file besar (lebih dari 100MB). Lihat [cara upload file besar menggunakan SFTP](/cara-upload-file-besar-menggunakan-sftp).
      </Step>
    </Steps>

  </Step>
  <Step title="Restart Server">
    <Steps>
      <Step title="Setelah semua mod selesai di-upload, klik tombol Restart di panel">
      </Step>
      <Step title="Tunggu sampai server menyala kembali">
      </Step>
      <Step title="Cek daftar mod di console">
        Kalau mod berhasil dimuat, daftar mod biasanya muncul di log console saat server startup.
      </Step>
    </Steps>
  </Step>
</Steps>

<Info>
## Tips Penting

- Gunakan mod dengan versi yang sesuai dengan server.
- Jangan mencampur mod dari loader yang berbeda. Mod Forge, Fabric, dan NeoForge tidak bisa dipakai bersamaan.
- Kalau server crash setelah memasang mod:
  1. Buka tab **Console**
  2. Cek error log
  3. Biasanya ada mod yang konflik atau tidak kompatibel

</Info>

<Tip>
  Mod yang tidak tersedia di panel, atau yang kamu dapat dari luar (misalnya
  dari website lain), bisa dipasang secara manual. Kalau butuh bantuan, tim kami
  siap membantu lewat [Setupin](https://setupin.com).
</Tip>

<Warning>
  Jangan mendownload atau memasang mod bajakan (*crack*) maupun dari sumber yang
  tidak jelas. Mod seperti ini sering mengandung malware, backdoor, atau script
  *crypto mining*. Sesuai [Terms of
  Service](/terms-of-service#langgaran-pengguna), server yang terbukti
  menjalankan file ilegal atau tidak aman dapat **dihentikan (terminate) tanpa
  pemberitahuan dan tanpa refund**. Semua file yang dijalankan di server menjadi
  tanggung jawab kamu sepenuhnya.
</Warning>
