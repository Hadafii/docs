## **MINECRAFT JAVA (KHUSUS PC/LAPTOP)**

<Info>
  Catatan: User PojavLauncher (HP) bisa join ke sini, tapi PC lebih diutamakan.
</Info>

### **Tipe MODS (Bisa Tambah Item/Blok/Mekanik Baru)**

> **Syarat:** Owner & Player **WAJIB** download file Mod di PC masing-masing agar bisa masuk.

- **Forge Enhanced (Forge):** "Raja" dari segala Mod. Paling lengkap koleksinya (Mobil, Senjata, Sihir). Agak berat untuk RAM.
- **Fabric:** Versi modern yang **SANGAT RINGAN**. Cocok untuk mod-mod terbaru dan PC spek rendah.
- **NeoForge:** Versi paling baru (penerus Forge). Sangat stabil untuk Minecraft versi 1.20 ke atas.

### **Tipe PLUGINS (Tambah Fitur Tanpa Download)**

> **Syarat:** Player tinggal masuk pakai IP. Tidak perlu download apa-apa.

- **Purpur:** **Sangat Direkomendasikan!** Paling ringan dan kamu bisa mengatur hal-hal unik (misal: naik ayam atau Ender Dragon).
- **Paper:** **Sangat Direkomendasikan!** Standar paling populer. Memperbaiki _bug_ Minecraft asli dan membuat server jauh lebih ringan.
- **Spigot:** Pendahulu Paper. Masih bagus, tapi performanya kalah jauh dibanding Paper/Purpur.
- **Sponge (SpongeVanilla):** Biasanya digunakan untuk server teknis atau sistem manajemen yang butuh API berbeda. Agak sulit untuk pemula.

### **Tipe HYBRID (Bisa Mod \+ Bisa Plugin)**

> **Syarat:** Bisa pasang Item Mod (Mobil/Pokemon) sekaligus sistem Rank/Uang (Plugin).

- **Arclight:** Hybrid paling stabil untuk Minecraft versi 1.16 sampai versi terbaru. Sedikit _bug_.
- **Mohist:** Alternatif Arclight. Terkenal bisa menjalankan hampir semua plugin, tapi kadang suka bentrok dengan Mod tertentu.
- **Magma:** Spesialis untuk Minecraft versi lama (seperti 1.12.2). Bagus untuk server modpack jadul.

### **Tipe POLOS (Vanilla)**

- **Vanilla Minecraft:** Tidak ada fitur tambahan. Benar-benar asli seperti baru beli. Paling boros RAM karena tidak ada optimasi kode.

## **KATEGORI 2: MINECRAFT BEDROCK (KHUSUS HP/MCPE/WIN10)**

<Info>
  Pemain Java PC tidak bisa masuk ke sini secara langsung tanpa bantuan khusus.
</Info>

- **Vanilla Bedrock:** Versi asli untuk HP. Paling stabil tapi tidak bisa dipasang fitur-fitur aneh (hanya bisa Add-on standar).
- **Pocketmine-MP:** **SANGAT CEPAT.** Tapi hati-hati: **Tidak ada hewan/zombie bawaan.** Biasanya hanya untuk server PVP atau Lobby.
- **Nukkit:** Lebih lengkap dari Pocketmine (mendukung blok & item lebih baik), tapi pluginnya tidak sebanyak Pocketmine.
- **Endstone:** Teknologi terbaru untuk server HP. Memungkinkan server HP punya fitur canggih sekelas server PC menggunakan bahasa Python.

**KATEGORI 3: FITUR KHUSUS (CROSSPLAY & NETWORK)**

- **Bungeecord:** Ini adalah **"Gerbang"**. Jika kamu ingin punya banyak server (Lobby, Survival, Bedwars) yang terhubung tanpa perlu ganti IP.
- **GEYSER Crossplay:** **WAJIB ADA** jika kamu ingin server PC (Java) kamu bisa dimasuki oleh teman yang menggunakan HP (Bedrock).
