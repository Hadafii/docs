# Downgrade Package

Kamu sekarang dapat melakukan **downgrade paket server** dengan beberapa ketentuan berikut:

## Syarat & Ketentuan

* Downgrade hanya dapat dilakukan apabila server dalam kondisi **aktif** (tidak berstatus **Suspended** maupun **Terminated**).
* **Tidak ada refund** untuk proses downgrade. Downgrade hanya mengubah paket agar biaya **renewal berikutnya** menjadi lebih rendah sesuai paket baru.
* Downgrade hanya dapat dilakukan **dalam kategori paket yang sama**:

  * Premium → Premium ✅
  * Basic → Basic ✅
  * Premium → Basic ❌
  * Basic → Premium ❌

## Cara Melakukan Downgrade

Untuk mengajukan downgrade paket, silakan hubungi tim kami melalui:

* **Ticket Discord**, atau
* **Ticket Website**

Tim kami akan membantu memproses permintaan downgrade sesuai dengan ketentuan yang berlaku.

> **Catatan**
>
> Jika ingin berpindah dari **Premium → Basic** atau **Basic → Premium**, downgrade tidak dapat dilakukan. Silakan membeli server baru dengan paket yang diinginkan, kemudian pindahkan data dari server lama ke server baru.
>
> * **Server lama masih aktif:** gunakan fitur **Importer** untuk memigrasikan data. Panduannya dapat dibaca di: [Cara Pindah / Migrasi Server](https://docs.raehost.com/cara-pindah-migrasi-server)
> * **Server lama sudah tidak aktif, tetapi Anda masih memiliki salinan datanya:** unggah kembali data tersebut ke server baru menggunakan SFTP. Panduannya dapat dibaca di: [Cara Upload File Besar Menggunakan SFTP](https://docs.raehost.com/cara-upload-file-besar-menggunakan-sftp)
