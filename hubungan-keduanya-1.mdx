---
title: "Hubungan Keduanya"
---

Website dan Panel memiliki fungsi yang berbeda, tetapi saling terhubung.

- Website digunakan untuk pembelian layanan, pembayaran, dan pengelolaan akun
- Panel digunakan untuk mengatur dan menjalankan server Minecraft setelah server aktif

Alurnya sangat sederhana:

<Step title="Pesan server melalui website RaeHost">
  Dapat dilakukan pada [https://clients.raehost.com/new-order](https://clients.raehost.com/new-order)
</Step>
<Step title="Lakukan Pembayaran hingga status berhasil">
  Pembayaran dapat dilakukan dengan berbagai metode, seperti QRIS,\_ Virtual Account, e-wallet,\_ dan credit card.
</Step>
<Step title="Server akan dibuat">
  Setelah pembayaran berhasil, server akan otomatis dibuat oleh sistem
</Step>
<Step title="Server akan langsung muncul di Panel">
  Setelah itu, server akan muncul di website Panel
</Step>
<Step title="Server siap dikelola dan digunakan">
  Setelah server muncul di Panel, kalian bisa kelola server nya
</Step>
