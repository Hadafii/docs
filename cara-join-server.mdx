---
title: "Cara Join Server"
---

Berikut adalah cara untuk join ke server yang sudah kamu miliki:

<Steps>
  <Step title="Cek Apakah Server Sudah Running?">
    Untuk melakukan pengecekan, silahkan akses ke `Panel > Console`. Pada bagian ini pastikan server sudah `running` seperti yang ditunjukkan pada gambar berikut:\\

    <Frame>
      ![Image](/images/image-36.png)
    </Frame>

    Pastikan server sudah `running` seperti yang ditunjukkan pada bagian 1. Jika belum `running`, silahkan klik tombol `start` seperti yang tertera pada bagian 2.
  </Step>
  <Step title="Temukan Server Address">
    Untuk menemukan server address, kamu bisa cari di `Panel > Console`. Server address ditandai dengan tulisan yang di _blur_.

    <Frame>
      ![Image](/images/image-37.png)
    </Frame>
  </Step>
  <Step title="Join ke Minecraft">
    Klik pada bagian _blur_ untuk meng-_copy_ server address.

        1. Server Name (bagian 1). Isi server name sesuai yang kamu inginkan. Misal server raehost, dunia kita, dll.

        3. Done (bagian 3) Tombol ini digunakan untuk membuat server ini ada di Minecraft kamu.

    <Steps>

            alt="Image"

        1. Server Name (bagian 1) Isi server name sesuai yang kamu inginkan. Misal server raehost, dunia kita, dll. 
        2. Server Address (bagian 2) Isi server address dengan hasil _copy_ pada `Panel`. Langsung `paste` server address yang sudah di _copy_ sebelumnya.
           <Note>
             Hapus port nya dan _copy-paste_ ke port pada bagian 3. \
             Contoh: \
             `Server Address = basic.raehost.com:100000`\
             Maka penulisan pada **Bedrock** adalah `Server Address = basic.raehost.com` `Port = 10000`
           </Note>
        3. Port (bagian 3) Paste port pada server address yang sudah di copy pada server address.
        4. Add Server (bagian 4) Tombol ini digunakan untuk membuat server ini ada di Minecraft kamu.
      </Step>
      <Step title="Masuk ke Server">
        <Frame>
          ![Image](/images/image-52.png)
        </Frame>

        1. Pastikan loading ping sudah berhasil, seperti yang ditunjukkan pada bagian 1.
        2. Jika loading ping sudah berhasil, klik `Play` seperti yang ditunjukkan pada bagian 2.
      </Step>

  </Step>
