5. Layanan dikelola menggunakan **panel manajemen server** untuk memudahkan pengguna dalam mengatur dan memantau server mereka.

## PERPANJANGAN DAN PENGHENTIAN LAYANAN

1. **Masa Aktif dan Perpanjangan**
   - Pengguna bertanggung jawab untuk melakukan **perpanjangan layanan** sebelum masa aktif berakhir.
   - Layanan akan **dinonaktifkan otomatis** setelah masa aktif habis.
2. **Penghapusan Data**
   - Data server akan **dihapus permanen** setelah melewati masa tenggang **3 (tiga) hari kalender** sejak tanggal kedaluwarsa.
   - RaeHost tidak bertanggung jawab atas kehilangan data akibat **keterlambatan pembayaran** atau **kelalaian pengguna**.
3. **Ketentuan Khusus Private Node**
   - Layanan **Private Node** akan **langsung dihentikan (_terminate_)** setelah melewati masa kadaluarsa **tanpa masa tenggang**.
   - Kebijakan ini diberlakukan karena **keterbatasan waktu sewa server fisik** yang digunakan untuk Private Node.
   - Pengguna Private Node sangat **disarankan untuk melakukan backup secara rutin** dan **memperpanjang layanan sebelum tanggal kedaluwarsa** untuk menghindari kehilangan data.
4. **Akses Backup Setelah Masa Kedaluwarsa**
   - Setelah layanan memasuki masa kedaluwarsa (_expired_), server akan berada dalam status suspend. Dalam kondisi ini, pengguna tidak memiliki akses ke data server, termasuk namun tidak terbatas pada: file server, database, dan backup.
   - Meskipun masih terdapat masa tenggang 3 (tiga) hari kalender, masa tenggang tersebut hanya diberikan untuk keperluan perpanjangan layanan, bukan untuk pengambilan data atau backup server.
   - Pengambilan backup atau data server saat masa kedaluwarsa hanya dapat dilakukan melalui permintaan khusus kepada tim RaeHost dan dikenakan biaya tambahan, sesuai dengan tingkat kesulitan dan durasi pengerjaan.
   - RaeHost berhak menolak permintaan pengambilan backup apabila data telah terhapus, sistem tidak memungkinkan, atau telah melewati masa penghapusan permanen.
   - RaeHost telah menyediakan fitur backup terjadwal (_scheduled backup_) melalui panel manajemen. Namun demikian, pengguna tetap bertanggung jawab untuk memastikan backup berjalan dengan baik, tersimpan dengan benar, dan melakukan backup tambahan secara mandiri apabila diperlukan sebelum masa aktif layanan berakhir.
5. **_Upgrade_ Server dan Sistem Prorata**

- Pengguna dapat melakukan **_upgrade_ paket server** kapan saja selama masa aktif layanan dengan sistem **pembayaran prorata (proporsional)**.
- Sistem prorata menghitung **selisih harga paket** berdasarkan **sisa waktu aktif server** yang masih tersedia.
- Server **tidak dapat di-_upgrade_**\_\_ apabila sudah memasuki **masa expired (kedaluwarsa)** atau dalam status **_suspend_**.
- Setelah _upgrade_ berhasil dilakukan, **masa aktif server akan tetap sama** dengan sebelumnya, hanya resource yang bertambah sesuai paket baru.
- Proses upgrade akan langsung memperbarui **alokasi resource (RAM, CPU, Storage, Database, Backup)** sesuai dengan paket yang dipilih.
