---
title: "Cara Install Simple Voice Chat"
---

<Note>
  Fitur ini hanya dapat dijalankan di Minecraft Java Edition.
</Note>

Ikuti langkah berikut untuk mengaktifkan fitur voice chat di server Minecraft kamu menggunakan plugin/mod Simple Voice Chat. Caranya tetap sama. 

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/). Pastikan server kamu offline.

    <Frame>
      <img
        src="/images/plugin/stop-server.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Install Plugin/Mod">
    <Frame>
      ![Image](/images/simple/search.png)
    </Frame>

    1. Masuk ke tab `Plugins` atau `Minecraft Mods`
    2. Cari `Simple Voice Chat`
    3. Klik `Install`
  </Step>
  <Step title="Pilih Sesuai Versi Server Kamu">
    <Frame>
      ![Image](/images/simple/install.png)
    </Frame>
  </Step>
  <Step title="Start Server Kembali">
    <Frame>
      ![Image](/images/simple/installed.png)
    </Frame>
  </Step>
  <Step title="Stop Server">
    Jika server sudah berstatus `running`, stop kembali server nya.

    <Frame>
      ![Image](/images/plugin/stop-server.png)
    </Frame>
  </Step>
  <Step title="Cari Port Voice">
    Masuk ke tab `Network`. Pastikan kamu memiliki 2 port. Copy port yang kedua (ditandai dengan tulisan `Make Primary`).

    <Frame>
      ![Image](/images/simple/network.png)
    </Frame>

    <Note>
      Jika kamu hanya memiliki 1 port pada tab `Network` silahkan buat tiket untuk meminta port tambahan. 
    </Note>
  </Step>
  <Step title="Konfigurasi File">
    Masuk ke tab `Files` kemudian cari file `plugins` seperti yang ditampilkan gambar berikut:

    <Frame>
      ![Image](/images/simple/config.png)
    </Frame>

    1. Masuk ke tab `Files`
    2. Masuk ke file `voicechat-server.properties`
    3. Masukkan port kedua mu
    4. Klik tombol `Save`
  </Step>
  <Step title="Restart Server">
    Kemudian klik tombol `Restart`pada console. Voice chat sudah running di port kedua kamu.

    <Frame>
      ![Image](/images/simple/works.png)
    </Frame>
  </Step>
  <Step title="Cek di Minecraft">
    Jika pada pojok kiri bawah minecraft kamu sudah terdapat icon voice, artinya voice sudah terinstall ke server kamu. 

    <Frame caption="Contoh icon">
      ![Image](/images/image-94.png)
    </Frame>
  </Step>
</Steps>
