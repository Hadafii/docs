---
title: "Cara Bikin Server Hytale"
---

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Kemudian stop server dengan menekan tombol `Stop` seperti yang ditunjukkan oleh nomor 2. Pastikan servermu offline seperti yang ditunjukkan oleh nomor 1.

    <Frame>
      ![Server Offline](/images/server-offline.png)
    </Frame>
  </Step>
  <Step title="Clean Install File (Jika Mau)">
    > **Hanya jika egg kalian belum Hytale**

    Pastikan di tab `Files`, bahwa semua file mu sudah tidak ada. Hal ini ditandai dengan `This directory seems to be empty` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![File Empty](/images/file-empty.png)
    </Frame>

    Jika belum kosong (dan ingin clean install), bisa ikuti langkah-langkah ini:

    <Steps>
      <Step title="Select All dan Delete">
        <Frame>
          ![Clean Install](/images/clean-install.png)
        </Frame>

        1. Masuk ke tab `Files`
        2. Centang seperti pada nomor 2 untuk memilih semua file
        3. Klik tombol `Delete` seperti pada nomor 3
      </Step>
      <Step title="Klik Delete">
        <Frame>
          <img
            src="/images/modal-delete-file.png"
            alt="Modal Delete File"
            className="mx-auto"
            style={{ width:"72%" }}
          />
        </Frame>
      </Step>
      <Step title="File Akan Kosong">
        <Frame>
          ![File Empty](/images/file-empty.png)
        </Frame>
      </Step>
    </Steps>
  </Step>
  <Step title="Ubah Egg ">
    <Info>
      **Lakukan ini jika Egg pada servermu belum Hytale**
    </Info>

    Masuk ke tab `Egg Changer` . Kemudian cari Hytale dan klik `Change Egg` seperti gambar dibawah ini:

    <Frame>
      ![Hytale Off](/images/hytale-off.png)
    </Frame>

    Kemudian klik tombol `Change Egg` seperti gambar dibawah ini:

    <Frame>
      <img
        src="/images/modal-change-egg.png"
        alt="Modal Change Egg"
        title="Modal Change Egg"
        className="mx-auto"
        style={{ width:"86%" }}
      />
    </Frame>
  </Step>
  <Step title="Start Server">
    Jika install sudah berhasil, klik tombol `Start` pada tab `Console`

    <Frame>
      ![Start Hytale](/images/start-hytale.png)
    </Frame>
  </Step>
  <Step title="Lakukan Autentikasi">
    Untuk server Hytale, akan muncul link autentikasi pada console. Silahkan klik link tersebut.

    <Frame>
      ![Autentikasi Hytale](/images/autentikasi-hytale.png)
    </Frame>
  </Step>
  <Step title="Autentikasi Akun Melalui Hytale">
    Klik tombol `Approve` seperti dibawah ini.

    <Frame>
      <img
        src="/images/approve-autentikasi.png"
        alt="Approve Autentikasi"
        title="Approve Autentikasi"
        className="mx-auto"
        style={{ width:"85%" }}
      />
    </Frame>

    Kemudian klik Login menggunakan Google

    <Frame>
      <img
        src="/images/login-hytale.png"
        alt="Login Hytale"
        title="Login Hytale"
        className="mx-auto"
        style={{ width:"77%" }}
      />
    </Frame>

    Akun akan terverifikasi, seperti berikut

    <Frame>
      <img
        src="/images/authorize.png"
        alt="Authorize"
        title="Authorize"
        className="mx-auto"
        style={{ width:"90%" }}
      />
    </Frame>
  </Step>
  <Step title="Kembali ke Panel ">
    Masuk kembali ke tab `Console`, server sedang dibuat dengan ditandai seperti ini

    <Frame>
      ![Downloading](/images/downloading.png)
    </Frame>
  </Step>
  <Step title="Masukkan token">
    Selanjutnya server akan running seperti nomor 1. Kemudian akan muncul pemberitahuan seperti nomor 2.

    <Frame>
      ![Need Auth](/images/need-auth.png)
    </Frame>

    Pada console, tulis command ini dan kirim

    ```text
    /auth login device
    ```
  </Step>
  <Step title="Server Harus di Verifikasi lagi">
    <Frame>
      ![Link Verify](/images/link-verify.png)
    </Frame>

    Akan muncul link verifikasi seperti gambar diatas. Bisa klik link 1 atau 2. Sarannya, klik saja link nomor 2. Kemudian ikuti step 6.
  </Step>
  <Step title="Cek Status">
    Jika sudah berhasil diverifikasi, bisa tulis di console

    ```text
    /auth status
    ```

    Akan muncul informasi pengguna di tab `Console`
  </Step>
  <Step title="Copy Server Address">
    <Frame>
      ![Ambil Server Address](/images/ambil-server-address.png)
    </Frame>
  </Step>
  <Step title="Buka Hytale ">
    Klik menu `Servers` seperti gambar dibawah ini:

    <Frame>
      <img
        src="/images/server-hytale.png"
        alt="Server Hytale"
        title="Server Hytale"
        className="mx-auto"
        style={{ width:"72%" }}
      />
    </Frame>
  </Step>
  <Step title="Klik Add Server">
    <Frame>
      <img
        src="/images/add-server.png"
        alt="Add Server"
        title="Add Server"
        className="mx-auto"
        style={{ width:"84%" }}
      />
    </Frame>
  </Step>
  <Step title="Masukkan Server Address">
    Isi informasi yang dibutuhkan

    <Frame>
      <img
        src="/images/add-server-modal.png"
        alt="Add Server Modal"
        title="Add Server Modal"
        className="mx-auto"
        style={{ width:"81%" }}
      />
    </Frame>

    1. Isi `connection address` dengan server address yang sudah di copy pada tab `Console`
    2. Masukkan nama server yang kamu inginkan
    3. Klik tombol `Add Server`
  </Step>
  <Step title="Server Terbuat">
    Kamu bisa klik server yang sudah terbuat seperti ini

    <Frame>
      ![Server Jadi](/images/server-jadi.png)
    </Frame>
  </Step>
</Steps>
