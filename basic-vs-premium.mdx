---
title: "Basic vs Premium"
---

Kami menyediakan 2 jenis node hosting yang bisa disesuaikan dengan kebutuhan server kamu.

## Basic Node

### Cocok Untuk:

- Small communities
- Survival SMP biasa
- Casual gaming
- Server dengan plugin ringan–menengah

### Spesifikasi:

- CPU: **AMD Ryzen 7 9700X**
- RAM: DDR5
- Harga lebih hemat
- Lokasi: Singapore

### Recommended Untuk:

- Server teman-teman
- Player sedikit–menengah
- Vanilla / plugin ringan
- Server baru mulai

## Premium Node

### Cocok Untuk:

- Competitive gaming
- Larger communities
- Server dengan plugin/mod berat
- Server dengan banyak player online

### Spesifikasi:

- CPU: AMD Ryzen 9 9950X
- RAM: DDR5
- ~45% More Power
- Lokasi: Singapore

### Recommended Untuk:

- Public server
- Banyak entity/redstone
- Addon/modpack berat
- TPS lebih stabil saat ramai\\

## Apa Bedanya CPU dan RAM?

- **CPU** → mempengaruhi kecepatan proses server\
  (mob, chunk, plugin, redstone, TPS)
- **RAM** → mempengaruhi kapasitas server\
  (jumlah player, world, addon/mod)

## Pilih yang Mana?

| **Basic** | **Premium** |
| --- | --- |
| <ul><li>Server masih kecil</li></ul> | <ul><li>Server mulai ramai</li></ul> |
| <ul><li>Player belum banyak</li></ul> | <ul><li>Pakai plugin atau mod berat</li></ul> |
| <ul><li>Penggunaan ringan-menengah</li></ul> | <ul><li>Butuh performa maksimal</li></ul> |
