Pada halaman Panel, kamu dapat mengatur seluruh kebutuhan server Minecraft kamu.

Melalui panel ini, kamu bisa:

- Mengakses Console server secara langsung
- Upload world, plugin, addon, atau mod
- Mengubah tipe software server
- Mengatur startup dan environment server
- Melihat penggunaan resource server
- Mengelola file server melalui File Manager
- Restart, stop, atau start server kapan saja
- Membuat backup server
- Mengelola database
- Memberikan akses kepada pengguna lain

Panel digunakan untuk seluruh **pengaturan teknis** server Minecraft kamu.

---

# Menu pada Panel

## 🖥️ Console

Digunakan untuk melihat aktivitas server secara real-time dan menjalankan command Minecraft.

**Contoh penggunaan:**

- Menjalankan command. Lengkapnya bisa dibaca [disini](https://docs.raehost.com/basic-command-di-minecraft)
- Melihat error plugin atau mod
- Memantau aktivitas pemain

---

## 📁 Files

Digunakan untuk mengelola seluruh file server.

**Fitur yang tersedia:**

- Upload file
- Download file
- Edit file
- Membuat folder baru
- Menghapus file

**Contoh penggunaan:**

- Upload plugin `.jar`
- Upload world
- Mengubah `server.properties`. Lengkapnya dapat dibaca [disini](https://docs.raehost.com/cara-setting-server.properties).

> ⚠️ Hati-hati saat menghapus file karena dapat menyebabkan server gagal berjalan.

## 👥 Users

Menu **Users** digunakan untuk memberikan akses panel kepada pengguna lain agar mereka dapat membantu mengelola server.

### Cara Menambahkan User

<Steps>
  <Step title="Klik New User">
    Pada menu Users, klik tombol  untuk menambahkan pengguna baru.
  </Step>
  <Step title="Masukkan Email Pengguna">
    Masukkan alamat email akun pengguna yang ingin diberikan akses ke server.
  </Step>
  <Step title="Pilih Permission">
    Centang izin (permission) yang ingin diberikan, seperti akses Console, Files, Backups, atau fitur lainnya sesuai kebutuhan.
  </Step>
  <Step title="Klik Invite User">
    Setelah semua izin sudah sesuai, klik  untuk mengirimkan akses kepada pengguna tersebut.
  </Step>
</Steps>

> 💡 Gunakan fitur ini jika server dikelola oleh beberapa orang, seperti teman, staff, atau developer yang membutuhkan akses ke panel. **Berikan hanya permission yang diperlukan. Hindari memberikan akses penuh kepada orang yang tidak dipercaya karena mereka dapat mengubah konfigurasi server atau menghapus data.**

## 👤 Players

Menu **Players** digunakan untuk melihat dan mengelola pemain yang pernah bergabung ke server.

Melalui menu ini, kamu dapat:

- Melihat daftar seluruh pemain yang pernah masuk ke server.
- Melihat status pemain seperti Operator (OP) dan Whitelist.
- Mencari pemain menggunakan fitur pencarian.
- Melihat informasi pemain seperti Username dan UUID/XUID.
- Melakukan tindakan langsung kepada pemain tanpa perlu mengetik command di Console.

**Fitur yang Tersedia**

**Moderation**

- **Kick** — Mengeluarkan pemain dari server.
- **Kill** — Menghilangkan karakter pemain di dalam game.

**Permissions**

- **Whitelist** — Menambahkan atau menghapus pemain dari whitelist server.
- **Make OP** — Memberikan hak administrator (Operator/OP) kepada pemain.

**Gameplay**

- **Teleport** — Teleport ke pemain atau memindahkan pemain ke lokasi tertentu.
- **Gamemode** — Mengubah mode permainan pemain.
- **Whisper** — Mengirim pesan pribadi kepada pemain.
- **Give Item** — Memberikan item langsung kepada pemain.

**Attributes**

- **Set XP Level** — Mengatur level XP pemain.
- **Apply Effect** — Memberikan efek tertentu kepada pemain.
- **Clear Effects** — Menghapus seluruh efek aktif pada pemain.

**Data**

- **Clear Inventory** — Menghapus seluruh item yang dimiliki pemain.

> 💡 Menu ini mempermudah pengelolaan pemain tanpa perlu mengetik command Minecraft secara manual di Console.
