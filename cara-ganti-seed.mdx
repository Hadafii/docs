---
title: "Cara Ganti Seed"
---

> Disarankan untuk melakukan backup terlebih dahulu

## Java Edition

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    <Frame>
      <img
        src="/images/image-57.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Stop Server">
    Klik tombol `Stop` seperti yang ditampilkan oleh nomor 1. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/image-86.png)
    </Frame>
  </Step>
  <Step title="Hapus File World">
    Masuk ke tab `Files` kemudian hapus file berikut

    <Frame>
      ![Hapus World Java](/images/hapus-world-java.png)
    </Frame>

    1. Hapus file `world`, `world_nether`, dan `world_the_end `
    2. Klik tombol `Delete`

    Akan muncul informasi dan klik tombol `Delete` seperti gambaar berikut:

    <Frame>
      <img
        src="/images/delete-world-java.png"
        alt="Delete World Java"
        title="Delete World Java"
        className="mx-auto"
        style={{ width:"93%" }}
      />
    </Frame>
  </Step>
  <Step title="Ubah Seed">
    Terdapat 2 cara untuk merubah seed pada RaeHost. Kedua cara ini sama aja. Silahkan pilih salah satu:

    ### Melalui file `server.properties`

    <Steps>
      <Step title="Masuk ke tab Files">
        Masuk ke tab `Files`seperti yang ditampilkan pada nomor 1. Kemudian cari file server.properties seperti yang ditampilkan pada nomor 2.

        <Frame>
          ![Image](/images/image-62.png)
        </Frame>
      </Step>
      <Step title="Isi seed ">
        Cari baris `level-seed` seperti berikut:

        <Frame>
          ![Empty Level Seed](/images/empty-level-seed.png)
        </Frame>

        Isi seed sesuai yang kamu mau seperti nomor 1. Kemudian klik tombol `Save Content` seperti pada nomor 2.

        <Frame>
          ![Isi Level Seed](/images/isi-level-seed.png)
        </Frame>

        <Info>
          Jika ingin mengubah seed seperti yang di internet, pastikan versi minecraft nya sama.
        </Info>
      </Step>
      <Step title="Start Server">
        Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

        <Frame>
          ![Image](/images/image-67.png)
        </Frame>
      </Step>
    </Steps>

    ### Melalui tab `MC Config`

    <Steps>
      <Step title="Login ke Panel">
        Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

        <Frame>
          <img
            src="/images/image-57.png"
            alt="Image"
            title="Image"
            className="mx-auto"
          />
        </Frame>
      </Step>
      <Step title="Masuk ke tab MC Config">
        Cari `Level Seed` seperti gambar dibawah ini:

        <Frame>
          ![Level Seed Config](/images/level-seed-config.png)
        </Frame>

        Isi sesuai yang kamu mau, contoh:

        <Frame>
          <img
            src="/images/level-seed-terisi.png"
            alt="Level Seed Terisi"
            title="Level Seed Terisi"
            style={{ width:"94%" }}
          />
        </Frame>
      </Step>
      <Step title="Start Server">
        Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

        <Frame>
          ![Image](/images/image-67.png)
        </Frame>
      </Step>
    </Steps>
  </Step>
</Steps>
