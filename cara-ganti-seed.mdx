---
title: "Cara Ganti Seed"
---

> Disarankan untuk melakukan backup terlebih dahulu

## Java Edition

<Steps>
  <Step title="Stop Server">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Klik tombol `Stop` seperti yang ditampilkan oleh nomor 3. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/general/stop-server.png)
    </Frame>
  </Step>
  <Step title="Hapus File World">
    <Frame>
      ![Hapus World Java](/images/reset/delete-world-java.png)
    </Frame>

    1. Masuk ke tab `Files` 
    2. Hapus file `world`, `world_nether`, dan `world_the_end `
    3. Klik tombol `Delete`
  </Step>
  <Step title="Pilih Metode Delete">
    Ikuti tata cara berikut:

    <Frame>
      ![Image](/images/reset/modal-java.png)
    </Frame>

    Saat menghapus file, terdapat dua pilihan:
    1. **Trash**. File akan dipindahkan ke Trash dan masih dapat dipulihkan kembali jika diperlukan (maximal 7 hari).
    2. **Delete Permanently**. File akan dihapus secara permanen dan tidak dapat dikembalikan.
    > ⚠️ Pastikan memilih opsi yang sesuai karena **Delete Permanently** akan menghapus data secara permanen. 
  </Step>
  <Step title="Masukkan Seed">
    <Frame>
      ![Image](/images/seed/java-level-seed.png)
    </Frame>
    1. Masuk ke tab `Properties`
    2. Isi seed sesuai keinginanmu
    3. Klik `Save Changes`
  </Step>
  <Step title="Start Server">
    Kemudian start server dengan menekan tombol `Start`pada tab `Console` seperti yang ditunjukkan pada gambar berikut:

    <Frame>
      ![Image](/images/general/start-server.png)
    </Frame>
  </Step>
</Steps>

<Info>
  Jika suatu hari kamu ingin mengganti seed lagi, jangan lupa hapus file world nya terlebih dahulu
</Info>
