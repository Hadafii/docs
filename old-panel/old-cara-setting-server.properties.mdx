---
title: "Cara Setting server.properties"
---

File `server.properties` adalah file konfigurasi utama server Minecraft kamu. Di sini kamu bisa mengatur berbagai hal seperti gamemode, jumlah pemain, difficulty, dan banyak lagi.

Langsung lompat ke referensi properti yang kamu butuhkan:

- [Minecraft Java Edition](#minecraft-java-edition)
- [Minecraft Bedrock Edition](#minecraft-bedrock-edition)

---

Ada **dua cara** untuk mengatur server.properties di RaeHost:

---

## Cara 1: Melalui MC Configs (Direkomendasikan)

RaeHost menyediakan tampilan visual untuk mengubah pengaturan server tanpa perlu membuka file secara langsung.

<Frame>
  ![Image](/images/image-105.png)
</Frame>

<Steps>
  <Step title="Buka MC Configs">
    Di sidebar Panel, klik menu **MC Configs**.
  </Step>
  <Step title="Pilih Server Properties">
    Pada dropdown pertama, pilih **Server Properties**. Pada dropdown kedua, pilih tampilan **Visual** untuk tampilan form yang lebih mudah dibaca.
  </Step>
  <Step title="Ubah Pengaturan">
    Kamu bisa langsung mengubah pengaturan melalui form yang tersedia — dropdown, toggle, dan input field — tanpa perlu mengedit file secara manual.
  </Step>
  <Step title="Simpan">
    Setelah selesai, klik tombol **Save** dan **restart server** agar perubahan berlaku.
  </Step>
</Steps>

<Note>
  Tampilan **Visual** di MC Configs menampilkan semua opsi dalam bentuk form yang lebih mudah dipahami. Jika ingin mengedit file mentahnya langsung, pilih tampilan **Text**.
</Note>

---

## Cara 2: Edit File Langsung via File Manager

Cara manual dengan membuka file `server.properties` di **Panel → Files**.

<Tabs>
  <Tab title="Java Edition">
    ## Minecraft Java Edition

    ## Lokasi File

    File `server.properties` berada di root direktori server kamu. Buka melalui **Panel → Files** lalu cari file tersebut.

    ---

    ## Pengaturan Umum

    ### `motd`

    Pesan yang muncul di bawah nama server pada daftar server.

    ```text
    motd=A Minecraft Server
    ```

    > Mendukung warna dengan kode `\u00A7` (§), contoh: `motd=\u00A7aServer Saya`

    ---

    ### `max-players`

    Jumlah maksimal pemain yang bisa join ke server secara bersamaan.

    ```text
    max-players=20
    ```

    ---

    ### `gamemode`

    Mode permainan default untuk pemain yang baru join.

    | Nilai | Mode |
    | --- | --- |
    | `survival` | Survival |
    | `creative` | Creative |
    | `adventure` | Adventure |
    | `spectator` | Spectator |

    ```text
    gamemode=survival
    ```

    ---

    ### `difficulty`

    Tingkat kesulitan server.

    | Nilai | Keterangan |
    | --- | --- |
    | `peaceful` | Tidak ada mob musuh |
    | `easy` | Mob musuh ada, damage rendah |
    | `normal` | Standar |
    | `hard` | Damage lebih tinggi, kelaparan lebih berbahaya |

    ```text
    difficulty=easy
    ```

    ---

    ### `hardcore`

    Jika diaktifkan, pemain yang mati akan di-ban permanen dari server.

    ```text
    hardcore=false
    ```

    ---

    ### `force-gamemode`

    Jika `true`, pemain akan selalu kembali ke gamemode default saat join, meskipun sebelumnya sudah di-set manual.

    ```text
    force-gamemode=false
    ```

    ---

    ## Dunia

    ### `level-name`

    Nama folder dunia yang akan digunakan. Jika folder tidak ada, server akan membuatnya otomatis.

    ```text
    level-name=world
    ```

    ---

    ### `level-seed`

    Seed untuk generate dunia baru. Kosongkan untuk seed acak.

    ```text
    level-seed=
    ```

    ---

    ### `level-type`

    Tipe dunia yang akan di-generate.

    | Nilai | Keterangan |
    | --- | --- |
    | `minecraft:normal` | Dunia normal |
    | `minecraft:flat` | Dunia datar |
    | `minecraft:large_biomes` | Biome lebih besar |
    | `minecraft:amplified` | Terrain lebih ekstrem |

    ```text
    level-type=minecraft\:normal
    ```

    <Note>
      Tanda `\` sebelum `:` adalah escape character, jangan dihapus.
    </Note>

    ---

    ### `generate-structures`

    Apakah struktur seperti desa, dungeon, dll akan di-generate.

    ```text
    generate-structures=true
    ```

    ---

    ### `view-distance`

    Jarak render chunk yang dikirim ke client (dalam chunk). Makin besar, makin berat di RAM.

    ```text
    view-distance=10
    ```

    ---

    ### `simulation-distance`

    Jarak di mana entitas dan redstone aktif secara aktif. Lebih kecil dari `view-distance` dapat meningkatkan performa.

    ```text
    simulation-distance=10
    ```

    ---

    ### `max-world-size`

    Batas ukuran dunia dalam radius block dari titik 0,0.

    ```text
    max-world-size=29999984
    ```

    ---

    ## Keamanan & Akses

    ### `online-mode`

    Jika `true`, server akan memverifikasi akun pemain ke server Mojang. Matikan jika server kamu menggunakan mode cracked.

    ```text
    online-mode=true
    ```

    <Warning>
      Mematikan `online-mode` membuka server untuk pemain cracked. Gunakan plugin autentikasi seperti **AuthMe** jika online-mode dinonaktifkan.
    </Warning>

    ---

    ### `white-list`

    Aktifkan whitelist agar hanya pemain tertentu yang bisa join.

    ```text
    white-list=false
    ```

    > Cara setup whitelist bisa dilihat di [Cara Whitelist](/cara-whitelist).

    ---

    ### `enforce-whitelist`

    Jika `true`, pemain yang tidak ada di whitelist akan langsung di-kick meski sudah terlanjur join.

    ```text
    enforce-whitelist=false
    ```

    ---

    ### `spawn-protection`

    Radius area spawn yang tidak bisa diubah oleh pemain biasa (non-OP). Set ke `0` untuk menonaktifkan.

    ```text
    spawn-protection=16
    ```

    > Cara menonaktifkan spawn protection bisa dilihat di [Cara Menonaktifkan Spawn Protection](/cara-menonaktifkan-spawn-protection-di-server-minecraft).

    ---

    ### `op-permission-level`

    Level permission untuk OP.

    | Nilai | Keterangan |
    | --- | --- |
    | `1` | Bisa bypass spawn protection |
    | `2` | Bisa gunakan cheat commands |
    | `3` | Bisa manage player (ban, kick, dll) |
    | `4` | Akses penuh termasuk `/stop` |

    ```text
    op-permission-level=4
    ```

    ---

    ### `player-idle-timeout`

    Waktu (dalam menit) sebelum pemain idle di-kick. Set ke `0` untuk tidak ada batas.

    ```text
    player-idle-timeout=0
    ```

    ---

    ### `allow-flight`

    Izinkan pemain terbang tanpa plugin/mod. Aktifkan jika server kamu menggunakan Creative atau mod yang membutuhkan flight.

    ```text
    allow-flight=false
    ```

    ---

    ## Resource Pack

    ### `resource-pack`

    URL resource pack yang akan dikirim ke pemain saat join.

    ```text
    resource-pack=
    ```

    ---

    ### `require-resource-pack`

    Jika `true`, pemain yang menolak resource pack tidak bisa masuk ke server.

    ```text
    require-resource-pack=false
    ```

    ---

    ### `resource-pack-prompt`

    Pesan yang ditampilkan ke pemain saat ditawarkan resource pack.

    ```text
    resource-pack-prompt=
    ```

    ---

    ## Jaringan

    ### `server-port`

    Port yang digunakan server. Default Minecraft Java adalah `25565`.

    ```text
    server-port=25565
    ```

    ---

    ### `network-compression-threshold`

    Ukuran paket (bytes) minimum sebelum dikompresi. Naikkan jika koneksi lambat, turunkan untuk koneksi cepat.

    ```text
    network-compression-threshold=256
    ```

    ---

    ### `prevent-proxy-connections`

    Blokir pemain yang menggunakan VPN atau proxy.

    ```text
    prevent-proxy-connections=false
    ```

    ---

    ### `rate-limit`

    Batas paket per detik per koneksi. `0` = tidak ada batas.

    ```text
    rate-limit=0
    ```

    ---

    ## Fitur Lanjutan

    ### `enable-rcon`

    Aktifkan RCON untuk kontrol server jarak jauh via aplikasi eksternal.

    ```text
    enable-rcon=false
    ```

    ---

    ### `rcon.port` & `rcon.password`

    Port dan password untuk koneksi RCON.

    ```text
    rcon.port=25575
    rcon.password=
    ```

    ---

    ### `enable-query`

    Aktifkan query protocol untuk melihat info server dari luar.

    ```text
    enable-query=false
    ```

    ---

    ### `max-tick-time`

    Waktu maksimal (ms) per tick sebelum server dianggap hang dan di-restart otomatis. Set ke `-1` untuk menonaktifkan.

    ```text
    max-tick-time=60000
    ```

    ---

    ### `sync-chunk-writes`

    Tulis chunk ke disk secara sinkron. Matikan untuk performa lebih baik, tapi berisiko korupsi data jika server crash.

    ```text
    sync-chunk-writes=true
    ```
  </Tab>
  <Tab title="Bedrock Edition">
    ## Minecraft Bedrock Edition

    ## Lokasi File

    File `server.properties` berada di root direktori server kamu. Buka melalui **Panel → Files** lalu cari file tersebut.

    ---

    ## Pengaturan Umum

    ### `server-name`

    Nama server yang muncul di daftar server pemain.

    ```text
    server-name=Bedrock Dedicated Server
    ```

    ---

    ### `gamemode`

    Mode permainan default untuk pemain yang baru join.

    | Nilai | Mode |
    | --- | --- |
    | `survival` | Survival |
    | `creative` | Creative |
    | `adventure` | Adventure |

    ```text
    gamemode=survival
    ```

    ---

    ### `difficulty`

    Tingkat kesulitan server.

    | Nilai | Keterangan |
    | --- | --- |
    | `peaceful` | Tidak ada mob musuh |
    | `easy` | Damage rendah |
    | `normal` | Standar |
    | `hard` | Damage tinggi |

    ```text
    difficulty=easy
    ```

    ---

    ### `force-gamemode`

    Jika `true`, pemain selalu kembali ke gamemode default saat join.

    ```text
    force-gamemode=false
    ```

    ---

    ### `allow-cheats`

    Izinkan penggunaan cheat command seperti `/give`, `/tp`, dll.

    ```text
    allow-cheats=false
    ```

    ---

    ### `max-players`

    Jumlah maksimal pemain yang bisa join secara bersamaan.

    ```text
    max-players=10
    ```

    ---

    ### `online-mode`

    Verifikasi akun pemain ke server Microsoft/Xbox. Matikan untuk mode cracked.

    ```text
    online-mode=true
    ```

    <Warning>
      Mematikan `online-mode` membuka server untuk pemain tanpa akun resmi. Pastikan kamu paham risikonya.
    </Warning>

    ---

    ### `allow-list`

    Aktifkan whitelist agar hanya pemain tertentu yang bisa join.

    ```text
    allow-list=false
    ```

    ---

    ## Dunia

    ### `level-name`

    Nama folder dunia yang digunakan.

    ```text
    level-name=default
    ```

    ---

    ### `level-seed`

    Seed untuk generate dunia baru. Kosongkan untuk seed acak.

    ```text
    level-seed=
    ```

    ---

    ### `default-player-permission-level`

    Level permission default untuk pemain baru.

    | Nilai | Keterangan |
    | --- | --- |
    | `visitor` | Hanya bisa melihat |
    | `member` | Pemain biasa |
    | `operator` | Akses OP |

    ```text
    default-player-permission-level=member
    ```

    ---

    ## Render & Performa

    ### `view-distance`

    Jarak render chunk (dalam chunk). Makin besar, makin berat.

    ```text
    view-distance=32
    ```

    ---

    ### `tick-distance`

    Jarak di mana chunk aktif secara simulasi (mob, redstone, dll).

    ```text
    tick-distance=4
    ```

    ---

    ### `max-threads`

    Jumlah thread CPU yang digunakan server. `0` = otomatis sesuai CPU.

    ```text
    max-threads=8
    ```

    ---

    ### `client-side-chunk-generation-enabled`

    Izinkan client generate chunk sendiri untuk performa lebih baik.

    ```text
    client-side-chunk-generation-enabled=true
    ```

    ---

    ## Jaringan

    ### `server-port`

    Port untuk koneksi IPv4. Default Bedrock adalah `19132`, tapi RaeHost menggunakan port custom.

    ```text
    server-port=25668
    ```

    ---

    ### `server-portv6`

    Port untuk koneksi IPv6.

    ```text
    server-portv6=19133
    ```

    ---

    ### `enable-lan-visibility`

    Tampilkan server di daftar LAN pemain.

    ```text
    enable-lan-visibility=true
    ```

    ---

    ### `player-idle-timeout`

    Waktu (menit) sebelum pemain idle di-kick. `0` = tidak ada batas.

    ```text
    player-idle-timeout=30
    ```

    ---

    ### `compression-threshold`

    Ukuran paket minimum (bytes) sebelum dikompresi.

    ```text
    compression-threshold=1
    ```

    ---

    ### `compression-algorithm`

    Algoritma kompresi yang digunakan.

    | Nilai | Keterangan |
    | --- | --- |
    | `zlib` | Kompresi standar, lebih kompatibel |
    | `snappy` | Lebih cepat, ukuran sedikit lebih besar |

    ```text
    compression-algorithm=zlib
    ```

    ---

    ## Keamanan & Custom Skin

    ### `texturepack-required`

    Paksa pemain untuk menggunakan texture pack server.

    ```text
    texturepack-required=false
    ```

    ---

    ### `disable-custom-skins`

    Nonaktifkan custom skin pemain dan ganti dengan skin default.

    ```text
    disable-custom-skins=false
    ```

    ---

    ### `disable-persona`

    Nonaktifkan skin Persona (karakter dari Marketplace).

    ```text
    disable-persona=false
    ```

    ---

    ### `chat-restriction`

    Batasi chat pemain.

    | Nilai | Keterangan |
    | --- | --- |
    | `None` | Chat bebas |
    | `Dropped` | Pesan chat tidak terkirim |
    | `Disabled` | UI chat disembunyikan |

    ```text
    chat-restriction=None
    ```

    ---

    ### `disable-player-interaction`

    Nonaktifkan interaksi antar pemain (PvP, dll).

    ```text
    disable-player-interaction=false
    ```

    ---

    ## Anti-Cheat (Server Authoritative Movement)

    ### `server-authoritative-movement-strict`

    Aktifkan validasi pergerakan pemain di sisi server untuk mencegah cheat.

    ```text
    server-authoritative-movement-strict=false
    ```

    ---

    ### `player-position-acceptance-threshold`

    Toleransi jarak posisi pemain (dalam blok) sebelum dianggap invalid.

    ```text
    player-position-acceptance-threshold=0.5
    ```

    ---

    ### `server-authoritative-block-breaking-pick-range-scalar`

    Pengali jarak maksimal pemain bisa menghancurkan blok dari server. `1.5` = 50% lebih jauh dari standar.

    ```text
    server-authoritative-block-breaking-pick-range-scalar=1.5
    ```

    ---

    ## Logging

    ### `content-log-file-enabled`

    Simpan log error konten (addon/behavior pack) ke file.

    ```text
    content-log-file-enabled=false
    ```

    ---

    ### `content-log-console-output-enabled`

    Tampilkan log konten di console server.

    ```text
    content-log-console-output-enabled=false
    ```

    ---

    ### `content-log-level`

    Level detail log konten.

    | Nilai | Keterangan |
    | --- | --- |
    | `info` | Informasi umum |
    | `warning` | Peringatan saja |
    | `error` | Error saja |

    ```text
    content-log-level=info
    ```
  </Tab>
