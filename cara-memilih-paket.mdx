---
title: "Panduan Memilih RAM"
---

Pemilihan RAM sangat penting untuk menjaga server tetap stabil dan lancar saat dimainkan.

## Bedrock Edition

<Tip>
  1-2 GB
</Tip>

### Cocok Untuk:

- Vanilla Bedrock
- Main bersama teman
- Player sedikit–menengah
- Addon ringan

### Recommended Untuk:

- Tidak memakai plugin/mod berat
- World masih normal
- Aktivitas server ringan

## Java/Geyser

<Tip>
  4 GB
</Tip>

### Cocok Untuk:

- Server Java Edition
- Crossplay Java \+ Bedrock (Geyser)
- Plugin menengah
- Survival public kecil–menengah

### Recommended Untuk:

- Pakai Paper/Purpur
- Menggunakan beberapa plugin
- Player online mulai ramai

## Modded / Banyak Plugin

<Tip>
  6\+ GB
</Tip>

### Cocok Untuk:

- Modpack
- Plugin banyak
- World besar
- Public server aktif

### Recommended Untuk:

- Menggunakan Forge/Fabric
- Banyak entity/redstone
- Addon/plugin berat
- TPS mulai turun saat ramai

  - Server crash
  - Restart otomatis
