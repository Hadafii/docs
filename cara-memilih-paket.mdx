---
title: "Panduan Memilih RAM"
---

Pemilihan RAM sangat penting untuk menjaga server tetap stabil dan lancar saat dimainkan.

<Info>
Angka RAM di bawah ini merupakan **minimum yang dibutuhkan** agar server dapat berjalan. Kebutuhan RAM setiap server dapat berbeda-beda tergantung penggunaan, seperti:

- Jumlah player yang online
- Plugin, addon, atau mod yang digunakan
- Ukuran world
- Jumlah entity, mob, dan redstone
- Chunk yang dimuat (loaded chunks)
- Aktivitas pemain dan fitur server lainnya

Apabila penggunaan RAM sudah tidak mencukupi, silakan lakukan upgrade paket dengan mengikuti panduan berikut:
https://docs.raehost.com/upgrade

Jika tidak terdapat paket upgrade yang tersedia, silakan hubungi kami melalui tiket Website atau Discord. Tim kami akan membantu melakukan migrasi ke node lain agar upgrade dapat dilakukan, **selama masih tersedia stok pada node tujuan**.
</Info>

## Bedrock Edition

<Tip>
  1-2 GB
</Tip>

### Cocok Untuk:

- Vanilla Bedrock
- Main bersama teman
- Player sedikit–menengah
- Addon ringan

### Recommended Untuk:

- Tidak memakai plugin/mod berat
- World masih normal
- Aktivitas server ringan

## Java/Geyser

<Tip>
  4 GB
</Tip>

### Cocok Untuk:

- Server Java Edition
- Crossplay Java \+ Bedrock (Geyser)
- Plugin menengah
- Survival public kecil–menengah

### Recommended Untuk:

- Pakai Paper/Purpur
- Menggunakan beberapa plugin
- Player online mulai ramai

## Modded / Banyak Plugin

<Tip>
  6\+ GB
</Tip>

### Cocok Untuk:

- Modpack
- Plugin banyak
- World besar
- Public server aktif

### Recommended Untuk:

- Menggunakan Forge/Fabric
- Banyak entity/redstone
- Addon/plugin berat
- TPS mulai turun saat ramai

<Warning>
Memilih RAM yang terlalu kecil dapat menyebabkan:

- Server crash
- Restart otomatis
- Lag atau TPS drop
- Chunk lambat dimuat
- Player timeout atau disconnect

Perlu diketahui bahwa kebutuhan RAM setiap server berbeda-beda. Apabila server mengalami kendala karena RAM tidak mencukupi, hal tersebut berada di luar cakupan support. Pastikan memilih paket yang sesuai dengan kebutuhan server, dan lakukan upgrade jika penggunaan RAM sudah mendekati batas.
</Warning>
