<Info>
  Untuk crossplay Java dan Bedrock, minimal RAM yang dibutuhkan adalah 4 GB. Pastikan RAM mu cukup ya. Karena kalau dibawah 4 GB, bisa menyebabkan Out of Memory (OOM) yang dapat menyebabkan world mu crash.
</Info>

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    <Frame>
      <img
        src="/images/image-57.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Stop Server">
    Klik tombol `Stop` seperti yang ditampilkan oleh nomor 1. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/image-86.png)
    </Frame>
  </Step>
  <Step title="Clean Install File (Jika Mau)">
    > **Hanya jika kalian ingin menghapus semua file ya!**

    Pastikan di tab `Files`, bahwa semua file mu sudah tidak ada. Hal ini ditandai dengan `This directory seems to be empty` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![File Empty](/images/file-empty.png)
    </Frame>

    Jika belum kosong (dan ingin clean install), bisa ikuti langkah-langkah ini:

    <Steps>
      <Step title="Select All dan Delete">
        <Frame>
          ![Clean Install](/images/clean-install.png)
        </Frame>

        1. Masuk ke tab `Files`
        2. Centang seperti pada nomor 2 untuk memilih semua file
        3. Klik tombol `Delete` seperti pada nomor 3
      </Step>
      <Step title="Klik Delete">
        <Frame>
          <img
            src="/images/modal-delete-file.png"
            alt="Modal Delete File"
            className="mx-auto"
            style={{ width:"72%" }}
          />
        </Frame>
      </Step>
      <Step title="File Akan Kosong">
        <Frame>
          ![File Empty](/images/file-empty.png)
        </Frame>
      </Step>
    </Steps>
  </Step>
  <Step title="Ubah Egg">
    Untuk melakukan ubah egg, kamu perlu masuk ke teb `Egg Changer` dan cari egg `[GEYSER] CROSSPLAY`. Klik `Change Egg` seperti pada nomor 2.

    <Frame>
      ![Change Egg](/images/change-egg.png)
    </Frame>

    Kemudian klik tombol `Change Egg` seperti gambar dibawah ini:

    <Frame>
      <img
        src="/images/modal-change-egg.png"
        alt="Modal Change Egg"
        title="Modal Change Egg"
        className="mx-auto"
        style={{ width:"86%" }}
      />
    </Frame>

    Jika sudah berubah, maka tombol `Change Egg` akan berubah menjadi warna hijau seperti berikut:

    <Frame>
      ![Egg Is Change](/images/egg-is-change.png)
    </Frame>
  </Step>
  <Step title="Ubah Versi">
    <Frame>
      ![Geyser Version](/images/geyser-version.png)
    </Frame>

    1. Masuk ke tab `Startup`
    2. Pada versi minecraft, **jangan** biarkan diisi `latest` tapi isi sesuai versi terbaru. 
    3. Untuk port, bisa diisi dengan port pada server address yang terdapat di tab `Console`
  </Step>
  <Step title="Reinstall Server">
    Untuk melakukan reinstall, kamu dapat masuk ke tab `Settings` seperti yang ditampilkan pada nomor 1. Untuk melakukan reinstall, kamu dapat klik tombol `Reinstall Server` seperti pada nomor 2.

    <Frame>
      ![Image](/images/image-96.png)
    </Frame>

    Kemudian akan muncul konfirmasi. Klik tombol `Yes, reinstall server` seperti pada gambar dibawah ini:

    <Frame>
      ![Image](/images/image-98.png)
    </Frame>
  </Step>
  <Step title="Kembali ke tab Console">
    Saat sedang installing, akan muncul persetujuan seperti berikut, klik tombol `Accept`

    <Frame>
      ![Acc Eula](/images/acc-eula.png)
    </Frame>

    Tunggu hingga tertuli `Server mark as running` seperti gambar dibawah ini:

    <Frame>
      ![Server Mark Running](/images/server-mark-running.png)
    </Frame>
  </Step>
</Steps>

## **"You need a Java Edition account to play on this server"**

Hal ini dapat disebkan karena Bedrock player dianggap belum “terautentikasi” karena Geyser belum diset ke mode Floodgate. Berikut adalah solusinya:

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    <Frame>
      <img
        src="/images/image-57.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Buka file ">
    <Frame>
      ![File Config](/images/file-config.png)
    </Frame>

    1. Masuk ke tab `Files` 
    2. Buka file `/plugins/Geyser-Spigot/config.yml`
    3. Cari `auth-type: online` 

    <Frame>
      ![Floodgate](/images/floodgate.png)
    </Frame>

    1. Ubah menjadi `auth-type: floodgate` seperti gambar diatas
    2. Setelahnya klik Save Content
  </Step>
  <Step title="Restart Server">
    Setelahnya, pergi ke tab `Console` seperti yang ditunjukkan pada nomor 1. Kemudian klik `Restart` seperti yang ditunjukkan pada nomor 2. Spawn Protection sudah mati.

    <Frame>
      ![Image](/images/image-60.png)
    </Frame>
  </Step>
</Steps>

<Note>
  Restart server setiap kali ubah **config**
</Note>
