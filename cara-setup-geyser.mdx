<Info>
  Untuk crossplay Java dan Bedrock, minimal RAM yang dibutuhkan adalah 4 GB. Pastikan RAM mu cukup ya. Karena kalau dibawah 4 GB, bisa menyebabkan Out of Memory (OOM) yang dapat menyebabkan world mu crash.
</Info>

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    <Frame>
      <img
        src="/images/general/login-panel.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Stop Server">
    Klik tombol `Stop` seperti yang ditampilkan oleh nomor 3. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/general/stop-server.png)
    </Frame>
  </Step>
  <Step title="Pilih Minecraft Java">
    Masuk ke tab `Egg Changer` seperti pada nomor 1. Kemudian klik tombol `Browse` seperti pada nomor 2.

    <Frame>
      ![Image](/images/geyser/choose-egg.png)
    </Frame>
  </Step>
  <Step title="Pilih Geyser">
    Cari `Geyser Crossplay` dan klik tombol `Select`

    <Frame>
      ![Image](/images/geyser/select.png)
    </Frame>
  </Step>
  <Step title="Isi Pilihan Berikut">
    <Frame>
      ![Image](/images/geyser/modal-select.png)
    </Frame>
    1. Reinstall Server. Centang opsi ini untuk menjalankan instalasi ulang menggunakan konfigurasi dari egg Geyser yang baru. (Better klik centang saja)
    2. Clear All Files. Centang opsi ini jika ingin menghapus seluruh file server sebelum mengganti egg. ⚠️ Semua data seperti world, plugin, dan konfigurasi akan terhapus.
    3. Klik tombol Confirm Change untuk menerapkan perubahan egg server.
  </Step>
  <Step title="Tunggu Installing Selesai">
    <Frame>
      ![Image](/images/geyser/installer.png)
    </Frame>
  </Step>
  <Step title="Klik Accept Eula">
    <Frame>
      ![Image](/images/geyser/accept-eula.png)
    </Frame>
  </Step>
  <Step title="Server Aktif">
    <Frame>
      ![Image](/images/general/start-running.png)
    </Frame>
  </Step>
</Steps>

## **"You need a Java Edition account to play on this server"**

Hal ini dapat disebkan karena Bedrock player dianggap belum “terautentikasi” karena Geyser belum diset ke mode Floodgate. Berikut adalah solusinya:

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    <Frame>
      <img
        src="/images/general/login-panel.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Buka file ">
    <Frame>
      ![File Config](/images/geyser/auth-online.png)
    </Frame>

    1. Masuk ke tab `Files` 
    2. Buka file `/plugins/Geyser-Spigot/config.yml`
    3. Cari `auth-type: online` 

    <Frame>
      ![Floodgate](/images/geyser/auth-floodgate.png)
    </Frame>

    1. Ubah menjadi `auth-type: floodgate` seperti gambar diatas
    2. Setelahnya klik Save Content
  </Step>
  <Step title="Restart Server">
    Setelahnya, pergi ke tab `Console` seperti yang ditunjukkan pada nomor 1. Kemudian klik `Restart` seperti yang ditunjukkan pada nomor 2. Spawn Protection sudah mati.

    <Frame>
      ![Image](/images/general/restart.png)
    </Frame>
    Tunggu hingga server online kembali, seperti ini:
    <Frame>
      ![Image](/images/general/start.png)
    </Frame>
  </Step>
</Steps>

<Note>
  Restart server setiap kali ubah **config**
</Note>
