## Perbedaan

Kamu harus tau dulu perbedaan resource pack dan behaviour pack

<Columns cols={2}>
  <Column>
    ### Resource Pack

    Mengubah **tampilan dan suara** game, tanpa mengubah gameplay utama.

    Contoh:

    - Texture block berubah HD
    - UI/menu berubah
    - Sound effect baru
    - Animasi entity beda
    - Model item/custom mob appearance

    Yang diubah:

    - Texture
    - Model
    - Font
    - Music/sound
    - Particle
    - Animasi visual
  </Column>
  <Column>
    ### Behaviour Pack

    Mengubah **cara kerja/gameplay** di Minecraft.

    Contoh:

    - Mob punya skill baru
    - Item punya fungsi custom
    - Sistem quest
    - Custom crafting
    - Addon senjata
    - Mob attack berbeda
    - Survival mechanics baru

    Yang diubah:

    - AI mob
    - Damage
    - Loot
    - Crafting recipe
    - Spawn rules
  </Column>
</Columns>

    Buka file `/home/container/resource_packs` seperti pada nomor 1. Kemudian drag and drop file zip atau bisa menggunakan tombol `Upload` seperti nomor 2. Setelah folder masuk, klik icon detail seperti pada nomor 3. Kemudian klik menu `Unarchive` seperti nomor 4.
