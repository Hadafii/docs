---
title: "Cara Ganti Icon Server"
---

<Steps>
  <Step title="Siapkan gambar atau logo server yang ingin digunakan">
  </Step>
  <Step title="Pastikan gambar memiliki ukuran 64x64 pixel dengan format .png">
    Jika ukuran belum sesuai, kamu bisa resize gambar melalui [https://www.simpleimageresizer.com/](https://www.simpleimageresizer.com/)
  </Step>
  <Step title="Buka tab `Files` pada panel RaeHost">
    <Frame>
      ![Image](/images/change-icon/part-1.png)
    </Frame>
    1. Masuk ke tab `Files`
    2. Klik icon yang ditunjukkan oleh nomor 2

    <Frame>
      ![Image](/images/change-icon/part-2.png)
    </Frame>
    1. Akan muncul pilihan `Change Server Icon`
    2. Masukkan file foto nya, akan tersimpan seperti ini:

    <Frame>
      ![Image](/images/change-icon/saved.png)
    </Frame>
  </Step>
  <Step title="Restart server melalui panel RaeHost, lalu icon pada Minecraft">
    Berikut adalah contoh 
    <Frame>
      ![Image](/images/change-icon/saved.png)
    </Frame>
  </Step>
</Steps>

<Info>
  Jika icon belum muncul, hapus dan tambahkan ulang IP server kamu di menu Multiplayer Minecraft.
</Info>
