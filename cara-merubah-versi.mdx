## Java Edition

### Melalui Tab Versions
<Steps>
  <Step title="Stop Server">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Klik tombol `Stop` seperti yang ditampilkan oleh nomor 3. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/general/stop-server.png)
    </Frame>
  </Step>
  <Step title="Pilih Egg yang Diinginkan">
    <Frame>
      ![Image](/images/ubah-egg/versions-choose-egg.png)
    </Frame>
    1. Masuk ke tab Versions
    2. Klik `Browse` pada egg yang kamu inginkan
  </Step>
  <Step title="Pilih Versi yang Diinginkan">
    <Frame>
      ![Image](/images/ubah-egg/versions-choose-version.png)
    </Frame>
    Contohnya adalah Spigot:
    1. Pilih Minecraft Version sesuai dengan versi server yang ingin digunakan.
    2. Pilih Build yang tersedia. Gunakan build terbaru (nomor build paling tinggi) untuk rekomendasi penggunaan.
    3. Klik Switch Version untuk menerapkan perubahan versi server.
  </Step>
  <Step title="Pilih Metode Penggantian Egg">
    <Frame>
      ![Image](/images/ubah-egg/versions-apply-switch.png)
    </Frame>
    Contohnya adalah Spigot:
    1. Pilih metode pembersihan file saat mengganti versi server:
    - Keep Existing Files: Tidak menghapus file server yang ada.
    - Smart Cleanup: Menghapus file yang berpotensi konflik (rekomendasi).
    - Full Cleanup: Menghapus seluruh file server sebelum mengganti versi.
    2. Centang otomatis menyetujui EULA Minecraft agar server dapat langsung dijalankan.
    3. Klik untuk penerapkan perubahan versi server sesuai pengaturan yang dipilih.
  </Step>
  <Step title="Start Server">
    <Frame>
      ![Image](/images/ubah-egg/versions-start.png)
    </Frame>
  </Step>
  <Step title="Tunggu Hingga Server Online">
    <Frame>
      ![Image](/images/ubah-egg/versions-online.png)
    </Frame>
  </Step>
</Steps>

#### Vanilla Java
<Steps>
  <Step title="Stop Server">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Klik tombol `Stop` seperti yang ditampilkan oleh nomor 3. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/general/stop-server.png)
    </Frame>
  </Step>
  <Step title="Masukkan versi yang sesuai">
    <Frame>
      ![Image](/images/ubah-versi/java-startup.png)
    </Frame>

    1. Masuk ke tab `Startup`
    2. Pilih docker yang sesuai dengan versi kamu
    3. Masukkan versi minecraft kamu
    > untuk mendapatkan docker berapa, kamu bisa cek [disini](#tabel-versi-minecraft-%26-java)
  </Step>
  <Step title="Reinstall Server">
    <Frame>
      ![Image](/images/ubah-versi/settings.png)
    </Frame>

    1. Masuk ke tab `Settings`
    2. Pilih menu `Reinstall Server`
    3. Masukkan nama server kamu (harus sama persis secara penulisan)
    4. Klik tombol `Reinstall Server`

    Kemudian akan muncul konfirmasi. Klik tombol `Yes, reinstall server` seperti pada gambar dibawah ini:

    <Frame>
      ![Image](/images/ubah-versi/confirm.png)
    </Frame>
  </Step>
  <Step title="Tunggu Installing">
    <Frame>
      ![Image](/images/ubah-versi/running-installer.png)
    </Frame>
  </Step>
  <Step title="Start Server">
    Server sudah berjalan dengan versi yang diinginkan.

    <Frame>
      ![Image](/images/ubah-versi/java-running.png)
    </Frame>
  </Step>
</Steps>

#### Forge
<Steps>
  <Step title="Stop Server">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu. Klik tombol `Stop` seperti yang ditampilkan oleh nomor 3. Jika sudah di stop, maka server akan `offline` seperti yang ditampilkan oleh nomor 2.

    <Frame>
      ![Image](/images/general/stop-server.png)
    </Frame>
  </Step>
  <Step title="Pergi ke Startup">
    <Frame>
      ![Image](/images/ubah-versi/forge-settings.png)
    </Frame>
    <Step title="Pilih Docker yang Sesuai">
      > untuk mendapatkan docker berapa, kamu bisa cek [disini](#tabel-versi-minecraft-%26-java)
    </Step>
    <Step title="Masukkan Versi Minecraft Kamu">
      Di bagian **Server Variables**, isi field **Minecraft Version** dengan versi Minecraft yang ingin digunakan. Contoh: `1.20.1`
    </Step>
    <Step title="Masukkan Forge Version">
      Isi field **Forge Version** dengan versi Forge yang ingin digunakan, menggunakan format:

      ```text
      (Versi Minecraft)-(Build Forge)
      ```

      Contoh: `1.20.1-47.4.20`

      <Note>
        Cek daftar versi Forge yang tersedia di [files.minecraftforge.net](https://files.minecraftforge.net/net/minecraftforge/forge/). Pastikan versi yang dimasukkan valid — jika salah, proses install akan gagal.
      </Note>
    </Step>
    <Step title="Pilih Build Type">
      Di field **Build Type**, pilih tipe build yang ingin digunakan:

      | Nilai | Keterangan |
      | --- | --- |
      | `recommended` | Versi stabil yang direkomendasikan |
      | `latest` | Versi terbaru (bisa belum stabil) |
    </Step>
  </Step>
  <Step title="Reinstall Server">
    <Frame>
      ![Image](/images/ubah-versi/settings.png)
    </Frame>

    1. Masuk ke tab `Settings`
    2. Pilih menu `Reinstall Server`
    3. Masukkan nama server kamu (harus sama persis secara penulisan)
    4. Klik tombol `Reinstall Server`

    Kemudian akan muncul konfirmasi. Klik tombol `Yes, reinstall server` seperti pada gambar dibawah ini:

    <Frame>
      ![Image](/images/ubah-versi/confirm.png)
    </Frame>
  </Step>
  <Step title="Tunggu Installing">
    <Frame>
      ![Image](/images/ubah-versi/running-installer.png)
    </Frame>
  </Step>
  <Step title="Start Server">
    Server sudah berjalan dengan versi yang diinginkan.

    <Frame>
      ![Image](/images/ubah-versi/forge-running.png)
    </Frame>
  </Step>
</Steps>

  - Pastikan world kamu cocok dengan versi server (hindari bug chunk).
  - Untuk Bedrock, update world hanya aman kalau versi server dan world sama.

</Warning>

## Tabel Versi Minecraft & Java

| Versi Minecraft | Java yang Dibutuhkan |
| --- | --- |
| 1.8 – 1.16.5 | Java 8 |
| 1.17 | Java 16 |
| 1.17.1 – 1.20.4 | Java 17 |
| 1.20.5 – 1.21.x | Java 21 |
| 1.21.11 – 1.26\+ | Java 25 |

<Warning>
  Pastikan versi Java sudah sesuai dengan versi Minecraft yang digunakan. Java yang salah akan menyebabkan server gagal start.
</Warning>
