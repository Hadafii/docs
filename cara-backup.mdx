### Bikin Jadwal Sendiri

<Tip>
  Auto-backup itu penting supaya file server kalian tetap aman kalau ada error, crash, atau salah edit world/plugin.
</Tip>

<Steps>
  <Step title="Login ke Panel">
    Untuk melakukan ini, kamu perlu login ke panel melalui [https://panel.raehost.com/](https://panel.raehost.com/) Kemudian pilih servermu.

    <Frame>
      <img
        src="/images/backup/login-panel.png"
        alt="Image"
        title="Image"
        className="mx-auto"
      />
    </Frame>
  </Step>
  <Step title="Membuat Jadwal">
    Klik tab `Schedules` seperti yang ditunjukkan pada nomor 1. Kemudian klik tombol `Create schedule`

    <Frame>
      ![Image](/images/backup/create-schedule.png)
    </Frame>
  </Step>
  <Step title="Isi Data">
    Isi kebutuhan seperti berikut: (Jika menggunakan tampilan lama, ditandai dengan menonaktifkan `Simple Interval Mode` seperti yang ditunjukkan pada nomor 2)

    > Artinya backup ini akan dilakukan setiap hari di jam 00.00

    Isi kebutuhan seperti berikut: (Jika menggunakan tampilan lama, ditandai dengan mengaktifkan `Simple Interval Mode` seperti yang ditunjukkan pada nomor 2)
    <Frame>

      <img

    Penjelasan untuk gambar diatas:
    1. Nomor 1 merupakan backup name.  Tulis nama backup kamu, contoh `Daiily Backup`.
    2. Nomor 2 merupakan toggle untuk mengaktifkan tampilan modal schedule.
    3. Nomor 3 merupakan jadwal schedule yang diinginkan.
    4. Nomor 4 menjelaskan apakah jadwal backup hanya berjalan jika server sedang online. (Better off aja, jadi kalau lagi offline pun di backup)
    5. Nomor 5 menjelaskan apakah jadwal akan terus berjalan. (Nyalakan saja agar selalu di backup)
    6. Nomor 6 merupakan tombol untuk membuat jadwal.
  </Step>
  <Step title="Jadwal Terbuat">
    Setelah kamu klik `create schedule` maka jadwal akan tersimpan.
    <Frame>

    </Frame>
  </Step>
</Steps>

Jika kamu ingin mengubah jadwal yang sudah ada, kamu mengubahnya dengan cara seperti ini:

<Steps>
  <Step title="Klik Tombol Edit Pada Jadwalmu">
    Untuk mengubah jadwal, kamu dapat klik jadwal yang sudah ada

    <Frame>
      ![Image](/images/backup/edit-schedule.png)
    </Frame>
  </Step>
  <Step title="Isi Data ">
    Setelah klik tombol `Edit`, akan muncul form yang dapat kamu ubah isinya.

    <Frame>
      <img
        src="/images/backup/editted-schedule.png"
        alt="Image"
        title="Image"
        className="mx-auto"
        style={{ width:"83%" }}
      />
    </Frame>
  </Step>
  <Step title="Data Berubah">
    Jika sudah klik tombol `Save Changes`. Data pun berubah.
  </Step>
</Steps>

Jika kamu ingin membuat task terjadawal bisa menggunakan `Task Scheduler` memungkinkan kamu membuat aksi otomatis untuk server, seperti menjalankan command, restart server, membuat backup, atau membersihkan file lama secara terjadwal.

<Steps>
  <Step title="Klik New Task">
    Untuk membuat task baru, kamu dapat klik tombol `New Task`

    <Frame>
      ![Image](/images/backup/new-task.png)
    </Frame>
  </Step>
  <Step title="Isi Data">
    <Frame>
      <img
        src="/images/backup/create-task.png"
        alt="Image"
        className="mx-auto"
        style={{ width:"87%" }}
      />
    </Frame>

    Berikut penjelasan untuk gambar diatas:

    1. Nomor 1 berisi action untuk task yang dapat dikerjakan seperti:
       1. **Send command** → menjalankan command otomatis
       2. **Send power action** → restart/stop/start server
       3. **Create backup** → membuat backup server
    2. Nomor 2 berguna untuk menentukan jeda waktu sebelum task ini dijalankan setelah task sebelumnya selesai.
    3. Nomor 3 berisi data atau perintah yang akan dijalankan sesuai action yang dipilih. Contoh: `say Server restarting in 5 minutes` `restart`
    4. Nomor 4 merupakan tombol yang jika diaktifkan, task berikutnya tetap akan berjalan meskipun task ini gagal dijalankan.
    5. Nomor 5 berguna untuk membuat task.
  </Step>
  <Step title="Task Akan Tersimpan">
    Jika kamu klik tombol `Create Task`, maka task akan tersimpan dan akan dijalankan oleh sistem sesuai jadwal.
  </Step>
</Steps>

### Jadwal dari RaeHost

Kalau kamu ingin backup terjadwal tapi malas membuat jadwal nya. Kamu bisa menggunakan jadwal yang sudah disediakan oleh RaeHost dengan cara berikut:

<Steps>
  <Step title="Gunakan Jadwal yang Sudah Ada">
    <Frame>
      ![Image](/images/backup/jadwal-raehost.png)
    </Frame>
    1. Masuk ke tab `Backups`
    2. Klik toggle `Automatic Backup`
    3. Jika ingin mengubah jadwal, klik tombol yang ditunjuk oleh nomor 3
  </Step>
  <Step title="Setuju Jadwal Dibuat">
    Ketika klik toggle `Automatic Backup`, akan muncul gambar seperti dibawah ini:
    <Frame>
      ![Image](/images/backup/agree-jadwal.png)
    </Frame>
    Klik tombol `I Understand, Enable`.
  </Step>
  <Step title="Jadwal Auto Backup Berhasil Diaktifkan">
  <Frame>
      ![Image](/images/backup/active-auto-backup.png)
    </Frame>
  </Step>
</Steps>
