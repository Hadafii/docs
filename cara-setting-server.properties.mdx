---
title: "Cara Setting server.properties"
---

File `server.properties` adalah file konfigurasi utama server Minecraft kamu. Di sini kamu bisa mengatur berbagai hal seperti gamemode, jumlah pemain, difficulty, dan banyak lagi.

Langsung lompat ke referensi properti yang kamu butuhkan:

- [Minecraft Java Edition](#minecraft-java-edition)
- [Minecraft Bedrock Edition](#minecraft-bedrock-edition)

---

Ada **dua cara** untuk mengatur server.properties di RaeHost:

---

## Cara 1: Melalui MC Configs (Direkomendasikan)

RaeHost menyediakan tampilan visual untuk mengubah pengaturan server tanpa perlu membuka file secara langsung.

<Frame>
  ![Image](/images/image-105.png)
</Frame>

<Steps>
  <Step title="Buka MC Configs">
    Di sidebar Panel, klik menu **MC Configs**.
  </Step>
  <Step title="Pilih Server Properties">
    Pada dropdown pertama, pilih **Server Properties**. Pada dropdown kedua, pilih tampilan **Visual** untuk tampilan form yang lebih mudah dibaca.
  </Step>
  <Step title="Ubah Pengaturan">
    Kamu bisa langsung mengubah pengaturan melalui form yang tersedia — dropdown, toggle, dan input field — tanpa perlu mengedit file secara manual.
  </Step>
  <Step title="Simpan">
    Setelah selesai, klik tombol **Save** dan **restart server** agar perubahan berlaku.
  </Step>
</Steps>

<Note>
  Tampilan **Visual** di MC Configs menampilkan semua opsi dalam bentuk form yang lebih mudah dipahami. Jika ingin mengedit file mentahnya langsung, pilih tampilan **Text**.
</Note>

---

## Cara 2: Edit File Langsung via File Manager

Cara manual dengan membuka file `server.properties` di **Panel → Files**, yang berada di root direktori server kamu.

<Tabs>
  <Tab title="Java Edition">
    ## Minecraft Java Edition

    ### Pengaturan Umum

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `motd` | `A Minecraft Server` | Pesan di bawah nama server pada daftar server. Mendukung kode warna `\u00A7` (§) |
    | `max-players` | `20` | Jumlah maksimal pemain yang bisa join bersamaan |
    | `gamemode` | `survival` | `survival` \| `creative` \| `adventure` \| `spectator` |
    | `difficulty` | `easy` | `peaceful` \| `easy` \| `normal` \| `hard` |
    | `hardcore` | `false` | Jika aktif, pemain yang mati akan di-ban permanen |
    | `force-gamemode` | `false` | Jika `true`, pemain selalu kembali ke gamemode default saat join |

    ---

    ### Dunia

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `level-name` | `world` | Nama folder dunia. Dibuat otomatis jika belum ada |
    | `level-seed` | _(kosong)_ | Seed untuk generate dunia baru. Kosongkan untuk acak |
    | `level-type` | `minecraft\:normal` | `minecraft\:normal` \| `minecraft\:flat` \| `minecraft\:large_biomes` \| `minecraft\:amplified`. Tanda `\` sebelum `:` wajib ada |
    | `generate-structures` | `true` | Generate struktur seperti desa, dungeon, dll |
    | `view-distance` | `10` | Jarak render chunk ke client (chunk). Makin besar, makin berat |
    | `simulation-distance` | `10` | Jarak entitas & redstone aktif. Lebih kecil dari `view-distance` = performa lebih baik |
    | `max-world-size` | `29999984` | Batas ukuran dunia (radius block dari titik 0,0) |

    ---

    ### Keamanan & Akses

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `online-mode` | `true` | Verifikasi akun ke Mojang. Matikan hanya untuk mode cracked \+ plugin auth seperti **AuthMe** |
    | `white-list` | `false` | Hanya pemain di whitelist yang bisa join. Lihat [Cara Whitelist](/cara-whitelist) |
    | `enforce-whitelist` | `false` | Pemain di luar whitelist langsung di-kick meski sudah join |
    | `spawn-protection` | `16` | Radius spawn yang tak bisa diubah non-OP. `0` = nonaktif. Lihat [caranya](/cara-menonaktifkan-spawn-protection-di-server-minecraft) |
    | `op-permission-level` | `4` | `1` bypass spawn protection · `2` cheat commands · `3` manage player · `4` akses penuh (`/stop`) |
    | `player-idle-timeout` | `0` | Menit sebelum pemain idle di-kick. `0` = tanpa batas |
    | `allow-flight` | `false` | Izinkan terbang tanpa mod/plugin |

    <Warning>
      Mematikan `online-mode` membuka server untuk pemain cracked. Gunakan plugin autentikasi seperti **AuthMe** jika dinonaktifkan.
    </Warning>

    ---

    ### Resource Pack

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `resource-pack` | _(kosong)_ | URL resource pack yang dikirim ke pemain saat join |
    | `require-resource-pack` | `false` | Pemain yang menolak resource pack tidak bisa masuk |
    | `resource-pack-prompt` | _(kosong)_ | Pesan saat resource pack ditawarkan |

    ---

    ### Jaringan

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `server-port` | `25565` | Port server Java |
    | `network-compression-threshold` | `256` | Ukuran paket (bytes) minimum sebelum dikompresi |
    | `prevent-proxy-connections` | `false` | Blokir pemain VPN/proxy |
    | `rate-limit` | `0` | Batas paket/detik per koneksi. `0` = tanpa batas |

    ---

    ### Fitur Lanjutan

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `enable-rcon` | `false` | Kontrol server jarak jauh via aplikasi eksternal |
    | `rcon.port` / `rcon.password` | `25575` / _(kosong)_ | Port & password koneksi RCON |
    | `enable-query` | `false` | Aktifkan query protocol untuk info server dari luar |
    | `max-tick-time` | `60000` | Batas ms per tick sebelum server dianggap hang & auto-restart. `-1` = nonaktif |
    | `sync-chunk-writes` | `true` | Tulis chunk ke disk sinkron. Matikan = performa naik, risiko korupsi data saat crash |

    ## Cara 2: Edit File Langsung via Tab Properties

    ## Pengaturan Umum

    ### `server-name`

    Nama server yang muncul di daftar server pemain.

    ```text
    server-name=Bedrock Dedicated Server
    ```

    ---

    ### `gamemode`

    Mode permainan default untuk pemain yang baru join.

    | Nilai | Mode |
    | --- | --- |
    | `survival` | Survival |
    | `creative` | Creative |
    | `adventure` | Adventure |

    ```text
    gamemode=survival
    ```

    ---

    ### `difficulty`

    Tingkat kesulitan server.

    | Nilai | Keterangan |
    | --- | --- |
    | `peaceful` | Tidak ada mob musuh |
    | `easy` | Damage rendah |
    | `normal` | Standar |
    | `hard` | Damage tinggi |

    ```text
    difficulty=easy
    ```

    ---

    ### `force-gamemode`

    Jika `true`, pemain selalu kembali ke gamemode default saat join.

    ```text
    force-gamemode=false
    ```

    ---

    ### `allow-cheats`

    Izinkan penggunaan cheat command seperti `/give`, `/tp`, dll.

    ```text
    allow-cheats=false
    ```

    ---

    ### `max-players`

    Jumlah maksimal pemain yang bisa join secara bersamaan.

    ```text
    max-players=10
    ```

    ---

    ### `online-mode`

    Verifikasi akun pemain ke server Microsoft/Xbox. Matikan untuk mode cracked.

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `server-name` | `Bedrock Dedicated Server` | Nama server di daftar server pemain |
    | `gamemode` | `survival` | `survival` \| `creative` \| `adventure` |
    | `difficulty` | `easy` | `peaceful` \| `easy` \| `normal` \| `hard` |
    | `force-gamemode` | `false` | Pemain selalu kembali ke gamemode default saat join |
    | `allow-cheats` | `false` | Izinkan cheat command seperti `/give`, `/tp` |
    | `max-players` | `10` | Jumlah maksimal pemain bersamaan |
    | `online-mode` | `true` | Verifikasi akun ke Microsoft/Xbox. Matikan untuk mode cracked |
    | `allow-list` | `false` | Hanya pemain di whitelist yang bisa join |

    <Warning>
      Mematikan `online-mode` membuka server untuk pemain tanpa akun resmi. Pastikan kamu paham risikonya.
    </Warning>

    ---

    ### Dunia

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `level-name` | `default` | Nama folder dunia yang digunakan |
    | `level-seed` | _(kosong)_ | Seed untuk generate dunia baru. Kosongkan untuk acak |
    | `default-player-permission-level` | `member` | `visitor` (lihat saja) \| `member` (biasa) \| `operator` (akses OP) |

    ---

    ### Render & Performa

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `view-distance` | `32` | Jarak render chunk (chunk). Makin besar, makin berat |
    | `tick-distance` | `4` | Jarak chunk aktif secara simulasi (mob, redstone, dll) |
    | `max-threads` | `8` | Jumlah thread CPU yang digunakan. `0` = otomatis |
    | `client-side-chunk-generation-enabled` | `true` | Izinkan client generate chunk sendiri untuk performa lebih baik |

    ---

    ### Jaringan

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `server-port` | `25668`\* | Port IPv4. Default Bedrock `19132`, RaeHost pakai port custom |
    | `server-portv6` | `19133` | Port IPv6 |
    | `enable-lan-visibility` | `true` | Tampilkan server di daftar LAN pemain |
    | `player-idle-timeout` | `30` | Menit sebelum pemain idle di-kick. `0` = tanpa batas |
    | `compression-threshold` | `1` | Ukuran paket minimum (bytes) sebelum dikompresi |
    | `compression-algorithm` | `zlib` | `zlib` (kompatibel) \| `snappy` (lebih cepat, ukuran lebih besar) |

    ---

    ### Keamanan & Custom Skin

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `texturepack-required` | `false` | Paksa pemain pakai texture pack server |
    | `disable-custom-skins` | `false` | Nonaktifkan custom skin, ganti ke skin default |
    | `disable-persona` | `false` | Nonaktifkan skin Persona (Marketplace) |
    | `chat-restriction` | `None` | `None` bebas \| `Dropped` pesan tak terkirim \| `Disabled` UI chat disembunyikan |
    | `disable-player-interaction` | `false` | Nonaktifkan interaksi antar pemain (PvP, dll) |

    ---

    ### Anti-Cheat (Server Authoritative Movement)

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `server-authoritative-movement-strict` | `false` | Validasi pergerakan pemain di server untuk mencegah cheat |
    | `player-position-acceptance-threshold` | `0.5` | Toleransi jarak posisi (blok) sebelum dianggap invalid |
    | `server-authoritative-block-breaking-pick-range-scalar` | `1.5` | Pengali jarak maksimal menghancurkan blok dari server (`1.5` = 50% lebih jauh) |

    ---

    ### Logging

    | Properti | Default | Keterangan |
    | --- | --- | --- |
    | `content-log-file-enabled` | `false` | Simpan log error konten (addon/behavior pack) ke file |
    | `content-log-console-output-enabled` | `false` | Tampilkan log konten di console server |
    | `content-log-level` | `info` | `info` \| `warning` \| `error` |
  </Tab>
</Tabs>
